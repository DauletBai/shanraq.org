# Аудио курса казахского языка

Здесь находятся кандидаты на аудио курса и, после утверждения, проверенные
записи казахского произношения. Текущий комплект создан локальным казахским
голосом `Aru (kk-KZ)` и ожидает проверки автора на странице `review.html`.

Требования к исходнику:

- носитель литературного казахского языка;
- тихое помещение без музыки, эха и шумоподавления, меняющего согласные;
- один файл на одну реплику по `manifest.json`;
- PCM WAV, 48 кГц, mono; предпочтительно 24 bit;
- 150–250 мс тишины до и после фразы;
- естественный спокойный темп, без послогового чтения;
- проверка вторым носителем перед переводом статуса записи в `approved`.

Уроки можно переключать на файл только после статуса `approved`. Так черновой
дубль не попадёт к ученику.
