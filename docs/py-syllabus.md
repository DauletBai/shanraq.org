# Python: что курс обязан объяснить

Список существует потому, что в курсе по Go пропуски нашлись не сразу: массивы,
константы, замыкания и рекурсия были не «отложены», а забыты, и закрывать их
пришлось задним числом. Здесь так не будет: каждый элемент языка назначен уроку
**до** того, как урок написан, и проверка это сверяет.

Как читать таблицу: **элемент** — то, что читатель должен уметь после курса;
**урок** — номер из [плана курса](py-course.md);
**маркеры** — слова, по которым проверка находит объяснение в тексте урока.

Маркер должен находиться во всех трёх языковых версиях урока, поэтому им берут
код — имя функции, аргумент, тег, — а не слово из прозы: русское «шкала» в
английском уроке не найдётся никогда.

Проверка запускается так:

```
python3 tools/coursecheck/pysyllabus.py plan                 # всё ли назначено
python3 tools/coursecheck/pysyllabus.py lesson 5 файл.md     # покрыл ли урок своё
```

## Правило

Урок не считается написанным, пока `pysyllabus.py lesson N файл.md` не сказал,
что все назначенные ему элементы в тексте есть. Если элемент решено перенести —
он переносится **в таблице**, а не забывается в голове.
