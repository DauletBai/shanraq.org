# SQL: семейный бюджет без догадок — карта курса

## Зачем этот курс

SQL нужен не только разработчику базы данных. Им пользуются аналитики,
инженеры, бухгалтеры, продуктовые команды и исследователи: когда факты лежат в
таблицах, SQL позволяет задать точный, повторяемый вопрос и получить ответ без
ручного копирования. Курс начинает с бытовой задачи, где цена ошибки понятна
каждому: куда уходит семейный доход, хватает ли обязательного резерва и какие
платежи повторяются незаметно.

## Обещание

Тринадцать уроков, после которых у читателя есть локальная SQLite-база
`budget.db` и проверяемый месячный отчёт. Она хранит счета, категории, операции
и лимиты; показывает доходы, расходы, остаток, долю обязательных трат,
накопительный итог и отклонение от плана. На компьютере база открывается через
`sqlite3`; на смартфоне, планшете и компьютере те же запросы выполняются в
локальной браузерной лаборатории. Данные не отправляются на сервер; между
занятиями база переносится через экспорт и восстановление файла `.sqlite`.

Это курс SQL, не курс конкретной программы. SQLite выбран потому, что ему не
нужен отдельный сервер и учётная запись, а база помещается в один файл.
На мобильном устройстве используется официальный SQLite WebAssembly: наличие
SQLite внутри операционной системы ещё не означает, что пользователь может
напрямую открыть системную базу. Переносимые конструкции отмечаются как SQL,
особенности SQLite — отдельно. Денежные суммы хранятся целыми тиынами, даты — в
ISO-формате `YYYY-MM-DD`, запросы приложения используют параметры.

## Методический контракт

Каждый урок проходит одну петлю: **образ → целое → разбор → опорная карта →
воспроизведение → маленькое обязательное задание → эталон**. Это применение
опорных сигналов и движения от целого к частям, связанных с методикой Виктора
Шаталова. Карта помогает восстановить ход мысли, но не заменяет выполнение
запроса.

Новые понятия вводятся только тогда, когда без них проект не может сделать
следующий шаг. Один урок — одна основная трудность. Примеры выполняются на RU,
KZ и EN с одинаковой схемой и числами; меняются только комментарии, подписи и
объяснения. После каждого изменения запускается автоматическая проверка базы.

## Границы курса

Курс охватывает переносимое ядро современного SQL и SQLite 3.46+: ограничения,
внешние ключи, соединения, CTE, оконные функции, транзакции, индексы и план
запроса. Он не выдаёт особенности SQLite за универсальный стандарт и не учит
администрированию PostgreSQL/MySQL, сетевой безопасности сервера, репликации и
распределённым транзакциям. Это следующий уровень.

Особые правила проекта:

- деньги — целое число тиынов, не `REAL`;
- `NULL` — неизвестно/неприменимо, а не ноль;
- внешние ключи включены явно: `PRAGMA foreign_keys = ON`;
- каждая запись имеет устойчивый первичный ключ;
- опасный `UPDATE` сначала превращается в `SELECT` с тем же `WHERE`;
- пользовательский ввод никогда не склеивается со строкой SQL;
- производительность измеряется через `EXPLAIN QUERY PLAN`, а не угадывается;
- резервная копия проверяется восстановлением.
