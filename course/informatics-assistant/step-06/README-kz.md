# 1.3 көмекші: оқу шекарасындағы қауіпсіздік

Бұл 1.2 нұсқасының жалғасы. Үш тапсырма мен төрт сабақ ойдан алынған. Python 3 керек, сыртқы пакет жоқ. Адамның нақты дерегін, құпиясөзін не сыныптасының файлын енгізбеңіз. Репозиторийді жүктеп, осы бумада терминал ашыңыз.

1. `python3 data_assistant.py init` тек жаңа `assistant.db` жасайды. Қайталап шақыру бұрынғысын алмастырмайды.
2. `python3 data_assistant.py report` нәтижесі: `t-01 45`, `t-02 0`, `t-03 25`. `t-02` нөлі — сабақ жазбасы жоқ деген сөз.
3. `python3 security_assistant.py verify assistant.db` SQLite тексерісінен соң `tasks=3 sessions=4` шығарады.
4. `python3 security_assistant.py backup assistant.db backups/first.db` жаңа көшірме мен `first.db.sha256` бақылау қосындысын жасайды.
5. `python3 security_assistant.py restore backups/first.db restored.db` көшірмені тексеріп, жаңа файл жасайды. Бар файл қайта жазылмайды. `python3 security_assistant.py verify restored.db` нәтижесін және `minutes_report("restored.db")` есебін салыстырыңыз.
6. `python3 web_assistant.py --port 8765` жергілікті бетті тек `127.0.0.1` мекенжайында ашады. Ctrl+C арқылы тоқтатыңыз.
7. `python3 -m unittest discover -s tests -v` бұрынғы ереже мен қалпына келтіруді тексереді.

Көшірме шифрланбайды. Оны сенімді бөлек құрылғыда сақтап, ортақ бумаға да, Git-ке де салмаңыз. Жанындағы бақылау қосындысы өзгерісті табуға көмектеседі, бірақ біреу екі файлды да ауыстырса, шынайылығын дәлелдемейді. Жергілікті `http.server` ішінде аккаунт жоқ, оны интернетке жариялауға болмайды.
