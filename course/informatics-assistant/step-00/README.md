# My Digital Assistant — step 00

This checkpoint contains no program yet. It proves that the learner can name a
person's observable problem before choosing a technology.

Use only fictional learning records. Do not put a learner's real name, marks,
messages, password, contacts, location history, or account tokens in this
project.

Copy `project-passport.template.md` to your own working directory and complete
it after lesson 2. The three example records will become test cases in later
checkpoints, so write concrete values rather than “something” or “any date”.

The course keeps checkpoints separate. A later checkpoint may copy and improve
this file, but it must not silently change the original problem. Every change
to the purpose belongs in the decision log with a reason.
