# Цифровой помощник 1.0

Это работающий результат уроков 27–38. Нужен Python 3.12 или новее; сторонние
библиотеки и сеть не нужны. Используйте только вымышленные учебные задачи.

Находясь в этой папке, выполните:

```sh
python3 assistant.py list
python3 assistant.py reminders --today 2026-10-09
python3 -m unittest discover -s tests -v
```

Ожидается `Completed: 1/3`; затем `t-01: REMIND`, `t-02: DONE`,
`t-03: NO_DATE`. Здесь `--today` фиксирует дату, чтобы опыт повторялся в любой
день. Без параметра используется календарная дата вашего компьютера.

Чтобы не менять пример, скопируйте `tasks.json` в другую папку и передайте её
путь после `--file` **до** команды. Примеры:

```sh
python3 assistant.py --file my-tasks.json add t-04 "Жоба жазу" --due 2026-10-11
python3 assistant.py --file my-tasks.json done t-04
python3 assistant.py --file my-tasks.json list
```

Файл версии 0.2 из предыдущего блока читается без изменений. Только `add` и
`done` записывают версию 1.0; они не придумывают старым задачам срок. Новый
формат хранит дату как `YYYY-MM-DD` или `null`. Ошибочный JSON, неверная дата
и повторный `id` отклоняются до записи. `assistant_core.py` хранит правила,
`assistant.py` обрабатывает команды, а папка `tests` проверяет обещания
бумажной версии 0.3.
