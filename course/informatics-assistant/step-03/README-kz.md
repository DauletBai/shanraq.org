# Цифрлық көмекші 1.0

Бұл — 27–38-сабақтардың жұмыс істейтін нәтижесі. Python 3.12 немесе одан жаңа
нұсқа керек; қосымша кітапхана мен желі қажет емес. Тек ойдан шығарылған оқу
тапсырмаларын қолданыңыз.

Осы буманың ішінде орындаңыз:

```sh
python3 assistant.py list
python3 assistant.py reminders --today 2026-10-09
python3 -m unittest discover -s tests -v
```

Алдымен `Completed: 1/3`, кейін `t-01: REMIND`, `t-02: DONE`,
`t-03: NO_DATE` шығуы тиіс. `--today` күнді бекітеді, сондықтан тәжірибені
кез келген күні қайталауға болады. Бұл параметр болмаса, компьютердің
жергілікті күнтізбелік күні алынады.

Үлгіні өзгертпеу үшін `tasks.json` файлын басқа бумаға көшіріп, оның жолын
командадан **бұрын** `--file` арқылы беріңіз:

```sh
python3 assistant.py --file my-tasks.json add t-04 "Жоба жазу" --due 2026-10-11
python3 assistant.py --file my-tasks.json done t-04
python3 assistant.py --file my-tasks.json list
```

Алдыңғы бөлімдегі 0.2 нұсқасының файлы өзгеріссіз оқылады. Тек `add` және
`done` 1.0 нұсқасын жазады; ескі тапсырмаларға мерзім ойдан қоспайды. Жаңа
пішімде күн `YYYY-MM-DD` не `null` түрінде сақталады. Бұзылған JSON, қате күн
және қайталанған `id` жазудан бұрын қабылданбайды. `assistant_core.py`
ережелерді, `assistant.py` командаларды қамтиды; `tests` бумасы қағаздағы
0.3 нұсқасының уәделерін тексереді.
