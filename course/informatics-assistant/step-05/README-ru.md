# Помощник 1.2: данные в SQLite

Это учебная контрольная точка с тремя вымышленными задачами и четырьмя вымышленными записями занятий. Не вводите реальные имена, оценки, сообщения или пароли. Нужен только Python 3 из предыдущего блока.

В этой папке выполните `python3 data_assistant.py init`. Команда читает `tasks.json` и `study_sessions.csv`, проверяет их и создаёт локальный `assistant.db`. При ошибке готовый файл не появится. Повторный `init` не заменяет уже созданную базу. Не отправляйте `assistant.db` в Git.

Проверьте `python3 data_assistant.py report`: ожидаются `t-01 45`, `t-02 0`, `t-03 25`. Ноль у `t-02` означает отсутствие записанных занятий, а не измеренную нулевую сессию. Запустите `python3 web_assistant.py --port 8765` и откройте `http://127.0.0.1:8765/?lang=ru&today=2026-10-09`. Статусы прежние: `REMIND`, `DONE`, `NO_DATE`. Для других языков используйте `lang=kz` и `lang=en`. Остановить сервер: Ctrl+C.

Проверка: `python3 -m unittest discover -s tests -v`. База и веб-страница работают **только локально**. Учебный `http.server` не предназначен для открытого интернета и не содержит учётных записей и разграничения прав.
