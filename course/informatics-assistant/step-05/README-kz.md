# 1.2 көмекшісі: SQLite ішіндегі деректер

Бұл — үш ойдан алынған тапсырма мен төрт ойдан алынған сабақ жазбасы бар оқу бақылау нүктесі. Нақты адамдардың есімін, бағасын, хабарын не құпиясөзін енгізбеңіз. Алдыңғы блоктағы Python 3 жеткілікті.

Осы бумада `python3 data_assistant.py init` орындаңыз. Пәрмен `tasks.json` және `study_sessions.csv` оқып, тексеріп, жергілікті `assistant.db` жасайды. Қате болса, дайын файл шықпайды. Қайталанған `init` бар базаны алмастырмайды. `assistant.db` файлын Git-ке жібермеңіз.

`python3 data_assistant.py report` нәтижесін тексеріңіз: `t-01 45`, `t-02 0`, `t-03 25`. `t-02` жанындағы нөл тіркелген сабақ жоқ дегенді білдіреді, өлшенген нөл минут емес. `python3 web_assistant.py --port 8765` қосып, `http://127.0.0.1:8765/?lang=kz&today=2026-10-09` ашыңыз. Бұрынғы күйлер: `REMIND`, `DONE`, `NO_DATE`. Басқа тіл үшін `lang=ru` не `lang=en` қолданыңыз. Тоқтату: Ctrl+C.

Тексеру: `python3 -m unittest discover -s tests -v`. База мен веб-бет **тек жергілікті** жұмыс істейді. Оқу `http.server` ашық интернетке арналмаған; онда пайдаланушы есептері мен қолжетімділік құқықтары жоқ.
