# Цифрлық көмекші алгоритмдері, 0.3 нұсқасы

Бұл — болашақ бағдарламаға арналған қағаздағы келісім. Үш бастапқы ойдан
шығарылған тапсырма `../step-01/data/tasks.json` ішінде өзгермейді. 0.2
форматында мерзім өрісі жоқ. Қалған күн саны `cases.json` тест карточкасынан
бөлек келеді; мерзімді файлға жазу кейін форматты бөлек жаңартуды қажет етеді.

## 1. Кірісті тексеру

Файлды UTF-8 түрінде ашып, JSON құрылымын оқу. `version="0.2"`, `tasks`
массивін, бос емес әрі бірегей `id` және `title`, логикалық `done` мәнін
тексеру. Қате болса, түсінікті хабар беру; жартылай деректі сенімді деп
көрсетпеу. Қайталанған `id` іздеу: бос `seen` жиынымен солдан оңға өту;
кезекті `id` ішінде бар болса, қатемен тоқтау, болмаса қосу. Инвариант:
`seen` ішінде дәл қаралған жазбалардың идентификаторлары бар.

## 2. Орындалған тапсырмаларды санау

Басы: `position=0`, `completed=0`. `position < len(tasks)` болғанда,
`tasks[position].done=true` болса, `completed` мәнін 1-ге арттыру; кейін
`position` мәнін 1-ге арттыру. `completed` қайтару. Бос тізім нәтижесі 0.
Инвариант: санағыш тек қаралған бөліктегі орындалғандар санына тең. Әр
айналымда орын өсетіндіктен алгоритм аяқталады.

## 3. Еске салуды шешу

`should_remind(done, days_to_due)` логикалық күйді және күнтізбелік күннің
бүтін санын не мерзімнің жоқтығын алады. Ол **файлды өзгертпейді**.

| Ретімен тексеру | Нәтиже |
|---|---|
| `done=true` | `DONE` |
| мерзім жоқ | `NO_DATE` |
| `days_to_due < 0` | `OVERDUE` |
| `0 ≤ days_to_due ≤ 2` | `REMIND` |
| басқа күндер | `NOT_YET` |

`cases.json` карточкаларын қайталасаңыз, `2026-10-09` тұрақты күнін және
`Asia/Qostanay` белдеуін қолданыңыз. Күнтізбелік күн мен дәл 24 сағаттық
аралықты шатастырмаңыз. Мерзімнің жоқтығы 0-ге тең емес.

## 4. Трасса және қабылдау

`false, true, false` үшін санағыш `0 → 0 → 1 → 1` күйлерінен өтіп, 1 береді.
`done=false` және `−1, 0, 1, 2, 3` күн үшін жауаптар: `OVERDUE, REMIND,
REMIND, REMIND, NOT_YET`. `done=true` болса, әрдайым `DONE`. Қайталанған
`id` санау мен еске салудан бұрын қабылданбайды.

Өзге оқушы тек осы құжат пен `cases.json` арқылы дәл сондай жауап алуы тиіс.
26-сабақтың 10 тармағын белгілеңіз: қазір 8/10, оның ішінде қайталанған
`id` мен 48 сағатқа жаңа көшіру міндетті; жеті күннен кейін жаңа мысалда
7/10. Сәйкеспеген жауаптың ережесін түзеп, ұқсас тестті қайталаңыз. Бұл
нұсқа хабарлама жібермейді.
