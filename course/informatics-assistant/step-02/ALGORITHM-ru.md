# Алгоритмы цифрового помощника, версия 0.3

Это бумажный договор для будущей программы. Три исходные вымышленные задачи
остаются в `../step-01/data/tasks.json`. Поля срока в формате 0.2 нет. Число
дней до срока приходит из отдельной тестовой карточки `cases.json`; запись
срока в файл потребует отдельного изменения формата в следующем блоке.

## 1. Проверить вход

Открыть файл в UTF-8 и разобрать JSON. Проверить `version="0.2"`, массив
`tasks`, непустые уникальные `id` и `title`, логический `done`. При ошибке
вернуть понятное сообщение и не показывать частичные данные как достоверные.
Проверка повторных `id`: идти слева направо с пустым множеством `seen`;
если очередной `id` уже в нём, остановиться с ошибкой; иначе добавить его.
Инвариант: `seen` содержит ровно идентификаторы уже просмотренных записей.

## 2. Посчитать выполненные задачи

Начать с `position=0`, `completed=0`. Пока `position < len(tasks)`, увеличить
`completed` на 1, если `tasks[position].done=true`, затем увеличить `position`
на 1. Вернуть `completed`. Пустой список даёт 0. Инвариант: счётчик равен
числу выполненных записей в уже просмотренной части. После каждого шага
позиция увеличивается, значит алгоритм останавливается.

## 3. Решить, нужно ли напоминание

`should_remind(done, days_to_due)` получает логическое состояние и целое число
календарных дней либо отсутствие срока. Оно **не изменяет файл**.

| Проверка по порядку | Возвращаемый ответ |
|---|---|
| `done=true` | `DONE` |
| срок отсутствует | `NO_DATE` |
| `days_to_due < 0` | `OVERDUE` |
| `0 ≤ days_to_due ≤ 2` | `REMIND` |
| остальные даты | `NOT_YET` |

Для расчёта дней используйте фиксированную дату `2026-10-09` и часовой пояс
`Asia/Qostanay`, если повторяете карточки из `cases.json`. Не смешивайте
календарные дни с точными 24-часовыми интервалами. Отсутствие срока не равно 0.

## 4. Трассировка и приёмка

Для `false, true, false` подсчёт проходит состояния `0 → 0 → 1 → 1` и даёт 1.
Для `done=false` и дней `−1, 0, 1, 2, 3` ожидаются `OVERDUE, REMIND,
REMIND, REMIND, NOT_YET`. Для `done=true` — всегда `DONE`. Повторный `id`
отклоняется до подсчёта и напоминания.

Другой учащийся должен получить те же результаты только по этому документу и
`cases.json`. Отметьте 10 пунктов урока 26: 8/10 сейчас, включая проверку
повторного `id` и новый перенос на 48 часов; 7/10 на новом примере через
семь дней. Если какой-то ответ не совпал, исправьте правило и повторите
равноценный тест. Уведомления эта версия не отправляет.
