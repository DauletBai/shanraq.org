# Формат данных «Цифрового помощника» 0.2

Файл `data/tasks.json` сохранён в UTF-8 без BOM. Корень — объект с текстовым `version`, равным `"0.2"`, и массивом `tasks`. У каждой задачи ровно три обязательных поля: уникальный непустой текстовый `id`, непустой текстовый `title`, логическое `done` (`true` или `false` без кавычек). Порядок элементов массива задаёт порядок показа; порядок полей объекта значения не имеет. В учебном образце три вымышленные записи и ровно одно `true`. Реальные имена и личные сведения не добавляйте.

Проверка: откройте файл как UTF-8; разберите JSON; сверьте версию и поля; убедитесь в уникальности `id`, непустых названиях и логическом типе `done`; сравните резервную копию с исходником побайтно (`cmp` в Unix/macOS) или через два SHA-256 из доверенного локального источника. Корректный JSON сам по себе не означает, что копия точная. Не заменяйте оригинал единственной копией.

Контрольная точка: 8/10 сейчас и 7/10 через семь дней, включая перенос на новую вымышленную запись и точное сравнение копии. Условия проверок перечислены в уроке 18.
