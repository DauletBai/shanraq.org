# Веб-көмекші 1.1: жергілікті оқу нұсқасы

Бұл 1.0 нұсқасының жалғасы. `tasks.json` ішінде бұрынғы үш **ойдан алынған** тапсырма сақталған. Сервер оларды браузерде көрсетеді, бірақ өзгертпейді. Python стандарт кітапханасы ғана қолданылады. Оқушылардың шын аты, құпиясөзі, бағасы не хабарын енгізбеңіз.

## Іске қосу

Осы бумада `python3 web_assistant.py --port 8765` орындап, `http://127.0.0.1:8765/?lang=kz&today=2026-10-09` ашыңыз. Орысша не ағылшынша көру үшін `lang=ru` немесе `lang=en` таңдаңыз. Күнді пішін арқылы өзгертіңіз. Тоқтату үшін терминалда Ctrl+C басыңыз.

Күтілетін күйлер: `t-01 REMIND`, `t-02 DONE`, `t-03 NO_DATE`. `/?today=2026-02-29` — 400, `/missing` — 404, POST — 405. Тексеру: `python3 -m unittest discover -s tests -v`. Файлдың өзгермегенін `shasum -a 256 tasks.json` арқылы бұрын және кейін салыстырыңыз.

Сервер тек 127.0.0.1 мекенжайын тыңдайды, TLS-сіз HTTP қолданады және ашық интернетке арналмаған. Python құжаттамасы `http.server`-ді production үшін ұсынбайды. Болашақ «бұлт» кәсіби серверді, HTTPS, пайдаланушы есептік жазбаларын, құқық бөлуді, қорғалған сақтауды және бөлек жариялауды талап етеді. Бұл мүмкіндіктер әлі жасалмаған.

Бақылау нүктесінде бұрынғы `assistant_core.py` ережелері, бастапқы жазбалар, веб-көрініс, тесттер және осы нұсқау бар. Тек оқу шешімі саналы түрде қабылданды: қауіпсіздік пен дерекқор сабақтары әлі алда.
