# Веб-помощник 1.1: локальная учебная версия

Это продолжение версии 1.0. Файл `tasks.json` содержит те же три **вымышленные** задачи. Сервер показывает их в браузере, но не изменяет. Используется только стандартная библиотека Python. Не вводите реальные имена, пароли, оценки или сообщения учеников.

## Запуск

В этой папке выполните `python3 web_assistant.py --port 8765`, затем откройте `http://127.0.0.1:8765/?lang=ru&today=2026-10-09`. Для казахского и английского интерфейса замените `lang=ru` на `lang=kz` и `lang=en`. Дата выбирается через форму. Чтобы остановить сервер, нажмите Ctrl+C в терминале.

Ожидаемые статусы: `t-01 REMIND`, `t-02 DONE`, `t-03 NO_DATE`. `/?today=2026-02-29` отвечает 400, `/missing` отвечает 404, POST отвечает 405. Проверка: `python3 -m unittest discover -s tests -v`. До и после можно сравнить `shasum -a 256 tasks.json`.

Сервер слушает только 127.0.0.1, работает через HTTP без TLS и не рассчитан на открытый интернет. `http.server` по документации Python не подходит для боевой эксплуатации. Будущее «облако» потребует профессионального сервера, HTTPS, учётных записей, разграничения прав, защищённого хранения и отдельного развёртывания. Ничего этого здесь пока нет.

Контрольная точка хранит прежние правила `assistant_core.py`, исходные записи, веб-представление, тесты и эту инструкцию. Решение о чтении без записи осознанное: уроки безопасности и баз данных ещё впереди.
