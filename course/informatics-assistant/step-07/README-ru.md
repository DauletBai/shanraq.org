## Прежние шаги защиты и восстановления

Это продолжение версии 1.2. Три задачи и четыре занятия вымышлены. Python 3, без внешних пакетов. Не вводите реальные персональные данные, пароли или файлы одноклассников. Скачайте репозиторий и откройте терминал в этой папке.

1. `python3 data_assistant.py init` создаёт только новый `assistant.db`. Повторный вызов не заменяет базу.
2. `python3 data_assistant.py report` печатает `t-01 45`, `t-02 0`, `t-03 25`. Ноль у `t-02` означает отсутствие записей о занятиях.
3. `python3 security_assistant.py verify assistant.db` печатает `tasks=3 sessions=4` после проверки SQLite.
4. `python3 security_assistant.py backup assistant.db backups/first.db` создаёт новую копию и файл `first.db.sha256` с контрольной суммой.
5. `python3 security_assistant.py restore backups/first.db restored.db` проверяет копию и создаёт новый файл. Существующий файл не перезаписывается. Сравните `python3 security_assistant.py verify restored.db` и отчёт, запустив `python3 data_assistant.py report --db restored.db`.
6. `python3 web_assistant.py --port 8765` открывает локальную страницу только на `127.0.0.1`. Остановить Ctrl+C.
7. `python3 -m unittest discover -s tests -v` проверяет прежние правила и восстановление.

Копия не шифруется. Храните её отдельно на доверенном устройстве, не загружайте в общий каталог и не отправляйте в Git. Файл контрольной суммы рядом с копией помогает обнаружить изменение, но не доказывает подлинность, если кто-то способен заменить оба файла. Локальный `http.server` не имеет аккаунтов и не предназначен для публикации в интернете.
