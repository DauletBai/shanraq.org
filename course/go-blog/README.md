# Блог, который вы строите · Сіз құрып жатқан блог · The blog you are building

Курс [«Go тілі: нөлден өз блогыңызға дейін»](https://shanraq.org/course/go) учит язык на
отдельных маленьких программах. Здесь лежит вторая половина работы: один
проект, который растёт вместе с вами. Каждая папка — состояние блога после
определённого урока, и в ней нет ничего, что к этому уроку ещё не разобрано.

| Шаг | После урока | Что появилось |
|-----|-------------|---------------|
| [step-1](step-1) | Первая программа на Go: веб-сервер | Сервер отвечает браузеру одной строкой |
| [step-2](step-2) | Строки и руны | Одна статья: заголовок, счёт букв, время чтения, `if` |
| [step-3](step-3) | Словарь (map) | Список статей: срез держит порядок, словари — заголовки и объём |
| [step-4](step-4) | Первый тест | Те же файлы плюс `main_test.go` |
| [step-5](step-5) | Структура (struct) | Три словаря исчезли: `[]Article` вместо них |
| [step-6](step-6) | Пакеты и модули | Блог разложен на два пакета, у шага свой `go.mod` |

## Как запустить

```
go mod init blog
go run .
```

Затем откройте `http://localhost:8080`. Остановить — `Ctrl+C`.

Папку можно скопировать к себе целиком; `go mod init` вы уже делали в каждом
уроке, здесь то же самое. Если порт занят, замените `8080` на `8081`.

## Сіз құрып жатқан блог

Курс тілді жеке шағын бағдарламалармен үйретеді. Мұнда жұмыстың екінші жартысы
тұр: сізбен бірге өсетін бір жоба. Әр қалта — белгілі бір сабақтан кейінгі
блогтың күйі, және онда сол сабаққа дейін талданбаған ештеңе жоқ.

Іске қосу: қалтаны көшіріп алыңыз, `go mod init blog`, содан кейін `go run .`
және `http://localhost:8080`.

## The blog you are building

The course teaches the language on small separate programs. This is the other
half of the work: one project that grows with you. Each folder is the state of
the blog after a particular lesson, and it contains nothing that lesson has not
already covered.

To run: copy the folder, `go mod init blog`, then `go run .` and open
`http://localhost:8080`.
