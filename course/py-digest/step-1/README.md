# Step 1 — the first numbers

The state of the digest after lesson 1, *Why count for yourself*.

The program asks the World Bank for Kazakhstan's price index and for the
inflation of several countries, and prints both. It needs nothing but Python:
`urllib` and `json` come with the language.

```
python3 main.py
```

Needs the network. Everything it prints is measured at the moment it runs, so
the numbers move as the World Bank revises its series.
