# Тапсырмалар: файл жолын таңдау

1. https://www.rust-lang.org/tools/install бетін ашып, өз жүйеңізге арналған Rust-ты орнатыңыз. Жаңа терминал ашып, `cargo --version` арқылы тексеріңіз.
2. Жоба қалтасында `cargo run` орындаңыз.
3. Пәрмендегі жол ортадағы жолдан басым; екеуі де жоқ болса, ағымдағы қалтадағы `тапсырмалар.json` алынады. Бұл оқу үлгісінде мәндер кодқа тікелей берілген; файл әлі жасалмайды.
4. Cargo қате көрсетсе, мәтінін оқып, пәрменді `Cargo.toml` бар қалтада орындағаныңызды тексеріңіз.
