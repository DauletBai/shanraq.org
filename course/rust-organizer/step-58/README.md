# Органайзер 0.1.0

Собран для той ОС, на которой создан архив. Распакуйте все файлы, затем запустите `organizer --version` (Windows: `organizer.exe --version`). Этот учебный пример только показывает версию и пока не открывает файл задач. Файл задач будущего органайзера храните отдельно и сохраняйте его копию. На macOS/Linux, если распакованный файл не запускается из-за прав, выполните `chmod +x organizer` в этой папке. При ошибке прочитайте сообщение в stderr и не заменяйте данные пустым файлом.
