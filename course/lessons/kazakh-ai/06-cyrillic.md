# Урок 6. Читаем казахскую кириллицу без потерь

## Зачем это нужно

Если адрес на конверте переписать с заменой одной буквы, письмо попадёт не туда. Для модели `үй` и `уй` тоже разные записи. Прежде чем искать части слова, научим программу получать именно те знаки, которые ввёл человек.

## Подготовка и целая программа

Используйте папку `ai-course`, созданную во [втором уроке](https://shanraq.org/read/kazakh-ai-02-first-program?lang=ru). Если файла `club.py` нет, выполните шаги установки и запуска там. Создайте рядом файл `letters.py` как обычный текст в UTF-8. **UTF-8** — способ сохранить буквы в файле так, чтобы Python прочитал их без замены. В редакторе выберите UTF-8, если он предлагает кодировку.

```python
word = input("Сөз: ")
print(word)
```

Готовый файл этого шага доступен в [папке учебного проекта](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-06); сначала прочитайте объяснение кода в этом уроке.

Запустите `python3 letters.py` на macOS/Linux или `py letters.py` на Windows. После подсказки `Сөз: ` наберите `үй` и нажмите Enter. Экран покажет `Сөз: үй`, а следующей строкой — `үй`.

## Разбираем каждый шаг

`input(...)` останавливает программу и ждёт строку с клавиатуры. Текст в кавычках — подсказка человеку, он не входит в ответ. Enter завершает ввод. `word =` сохраняет ответ под именем `word`; `print(word)` показывает сохранённую строку. Переменную, знак `=`, кавычки и `print` мы уже разобрали во втором уроке. Двоеточие внутри кавычек — просто часть подсказки, не команда Python.

Казахская кириллица содержит буквы, которые легко потерять при перепечатке: `ә ғ қ ң ө ұ ү һ і` и их прописные формы. Пара `ү`/`у` различает знаки так же, как разные цифры в телефонном номере. Здесь программа сохраняет введённое, но ещё не проверяет, правильно ли написано слово. Латинское `y` не заменяет кириллическое `у`.

## Опорная карта

Клавиатура → `input` → строка в `word` → `print` → тот же текст. UTF-8 сохраняет буквы файла; при вводе нужно самому набрать нужные буквы.

## Восстановите и проверьте себя

Закройте код и восстановите две строки по карте. Объясните, откуда берётся слово на второй строке вывода. Затем введите `үй`, `өнер` и `қала` по очереди, каждый раз перезапуская программу. Для каждого слова вторая строка должна в точности повторять ваш ввод. Если видите странные знаки, проверьте раскладку и UTF-8 файла.

**Задание:** измените только подсказку на `Атау: ` и введите `мектеп`. **Подсказка:** меняется строка внутри `input(...)`, не имя `word`. **Эталон:** `word = input("Атау: ")`; после ввода экран показывает `Атау: мектеп`, затем `мектеп`. **Частая ошибка:** если написать `print("word")`, получится слово `word`, потому что кавычки задают буквальный текст, а не переменную.
