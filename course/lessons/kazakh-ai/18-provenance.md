# Урок 18. Источник и дата проверки

## Зачем это нужно

На доске объявлений время занятия полезно только тогда, когда понятно, кто повесил листок и когда его проверили. Добавим эти сведения к каждой карточке.

## Перед запуском

Скопируйте файлы этого шага. Новые поля: `source` — условный код исходного листа клуба, `checked_on` — дата проверки в записи `год-месяц-день`. Например, `2026-09-01` означает 1 сентября 2026 года; нули нужны для одинаковой длины. `club-sheet-01` здесь учебное обозначение, не ссылка на существующий документ.

```json
[
  {"club": "шахмат", "kind": "уақыт", "value": "бейсенбі, 15:00", "source": "club-sheet-01", "checked_on": "2026-09-01"},
  {"club": "шахмат", "kind": "орын", "value": "203-бөлме", "source": "club-sheet-01", "checked_on": "2026-09-01"}
]
```

Из корня проекта перейдите в папку шага и запустите программу:

```text
cd course/kazakh-ai/step-18
python3 source.py
```

В Windows вместо последней команды выполните `py source.py`.

```python
import json

with open("facts.json", encoding="utf-8") as file:
    facts = json.load(file)
club = input("Үйірме: ").lower()
kind = input("Мәлімет түрі: ").lower()
matches = []
for fact in facts:
    if fact["club"] == club and fact["kind"] == kind:
        matches.append(fact)
if len(matches) == 1:
    fact = matches[0]
    print("Дерек:", fact["value"])
    print("Дереккөз:", fact["source"])
    print("Тексерілген күні:", fact["checked_on"])
elif len(matches) == 0:
    print("білмеймін: дерек жоқ")
else:
    print("тоқта: бірнеше дерек табылды")
```

[Файл шага](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-18).

## Что делает программа

Поиск не изменился. При одном совпадении `fact = matches[0]` даёт короткое имя найденной карточке. Затем печатаем значение, источник и дату. Дата проверки не означает, что запись действует сегодня: срок действия появится в уроке 20. Сам источник тоже может содержать ошибку; программа пока лишь показывает происхождение ответа.

## Опорная карта

Ключи → одна карточка → значение + условный источник + дата проверки.

## Вспомните и проверьте

Введите `шахмат` и `орын`. Подсказка: ищите карточку, где совпали оба поля. Эталон: `Дерек: 203-бөлме`, `Дереккөз: club-sheet-01`, `Тексерілген күні: 2026-09-01`. Измените только `source` у этой карточки и проверьте новую строку. Частая ошибка: принимать дату проверки за срок годности.
