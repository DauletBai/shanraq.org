# Урок 16. Каталог проверенных записей

## Зачем это нужно

В библиотеке книга получает карточку с названием и полкой. Так же мы заведём карточку для каждого учебного сведения. Здесь «проверено» значит, что автор вымышленного клуба внёс запись в учебный каталог; это не утверждение о реальном расписании.

## Перед запуском

JSON — текстовый формат хранения данных. Представьте стопку карточек: квадратные скобки `[ ]` охватывают всю стопку, фигурные `{ }` — одну карточку, запятая отделяет карточки и поля. Имя поля и его значение пишут через двоеточие; текст всегда в двойных кавычках. `club` — название кружка, `kind` — вид сведений, `value` — содержание. Два одинаковых имени поля внутри одной карточки недопустимы в нашем каталоге. Файл `facts.json` сохраните в UTF-8 рядом с программой.

```json
[
  {"club": "шахмат", "kind": "уақыт", "value": "бейсенбі, 15:00"},
  {"club": "шахмат", "kind": "орын", "value": "203-бөлме"}
]
```

Из корня проекта перейдите в папку шага и запустите программу:

```text
cd course/kazakh-ai/step-16
python3 catalog.py
```

В Windows вместо последней команды выполните `py catalog.py`.

```python
import json

with open("facts.json", encoding="utf-8") as file:
    facts = json.load(file)
print("Жазба саны:", len(facts))
for fact in facts:
    print(fact["club"], fact["kind"], fact["value"])
```

[Файл шага](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-16).

## Что делает программа

`import json` подключает модуль стандартной библиотеки: набор готовых действий с JSON. `with open(...) as file` открывает файл на время вложенных строк и закрывает его после выхода из блока. `encoding="utf-8"` позволяет читать казахские буквы. `json.load(file)` превращает текст карточек в список Python. `fact["club"]` берёт поле одной карточки, как адрес на полке. `len` считает записи.

## Опорная карта

Файл JSON → список карточек → три поля каждой карточки → печать; пока никакого поиска и ответа.
