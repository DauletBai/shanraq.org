# 16-сабақ. Тексерілген жазбалар тізімі

## Бұл не үшін керек?

Кітапханада әр кітаптың атауы мен сөресі жазылған карточкасы болады. Біз де оқу мәліметтерінің әрқайсысына осындай жазба жасаймыз. Мұндағы «тексерілген» дегеніміз — ойдан алынған үйірме туралы мәліметті оқу тізіміне автор енгізді деген сөз. Бұл шын үйірменің кестесі емес.

## Іске қоспас бұрын

JSON — мәлімет сақтайтын мәтіндік пішім. Карточкалар тобын елестетіңіз: тік жақшалар `[ ]` бүкіл топты, ирек жақшалар `{ }` бір карточканы қоршайды. Үтір карточкалар мен өрістерді бөледі, қос нүкте өріс атауы мен мәнін ажыратады. Мәтін қос тырнақшаға алынады. `club` — үйірме атауы, `kind` — мәлімет түрі, `value` — мазмұны. Бір карточкада бір өріс атауын қайталамаңыз. `facts.json` файлын бағдарламаның қасына UTF-8 жазылымымен сақтаңыз.

```json
[
  {"club": "шахмат", "kind": "уақыт", "value": "бейсенбі, 15:00"},
  {"club": "шахмат", "kind": "орын", "value": "203-бөлме"}
]
```

Жоба түбірінен қадам қалтасына өтіп, бағдарламаны іске қосыңыз:

```text
cd course/kazakh-ai/step-16
python3 catalog.py
```

Windows жүйесінде соңғы пәрменнің орнына `py catalog.py` деп жазыңыз.

```python
import json

with open("facts.json", encoding="utf-8") as file:
    facts = json.load(file)
print("Жазба саны:", len(facts))
for fact in facts:
    print(fact["club"], fact["kind"], fact["value"])
```

[Қадам файлдары](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-16).

## Бағдарлама қалай жұмыс істейді?

`import json` JSON-мен жұмыс істейтін Python-ның дайын құралдарын қосады. `with open(...) as file` файлды ішіндегі жолдар орындалғанша ашық ұстап, содан соң жабады. `encoding="utf-8"` қазақ әріптерін дұрыс оқуға қажет. `json.load(file)` мәтіндегі карточкаларды Python тізіміне айналдырады. `fact["club"]` бір карточканың өрісін алады. `len` жазбаларды санайды.

## Тірек сызба

JSON файлы → карточкалар тізімі → әр карточканың үш өрісі → басып шығару; әзірше іздеу де, жауап та жоқ.

## Еске түсіріп, тексеріңіз

Кодты жауып, бір карточканың шекарасын көрсетіңіз. Содан соң `сурет / орын / 105-бөлме` карточкасын қосып, санын болжаңыз. Көмек: жаңа карточканы үтірмен бөліңіз. Үлгі нәтиже: `Жазба саны: 3` және `сурет орын 105-бөлме`. Жиі қате: JSON мәтінінің тырнақшасын ұмыту; мұндай файл оқылмайды.
