# Урок 21. Размечаем вопросы вручную

## Зачем это нужно

Учитель сначала пишет ответы к карточкам, а уже потом проверяет ученика. Для модели такая карточка состоит из вопроса и правильной учебной метки. Без ответов к примерам ей нечему учиться и нам нечем проверять ошибки.

## До программы

В `examples.json` записано 19 вымышленных вопросов. Каждая карточка имеет `text` — вопрос и `label` — метку: `уақыт` (спрашивают о времени), `орын` (о месте), `белгісіз` (другая тема или сразу два запроса). Метка — решение человека для упражнения, не ответ о расписании. Перед разметкой спросите: «Какие сведения хочет человек?» Если ни один из двух видов не подходит, не выдумывайте метку.
```python
import json

with open("examples.json", encoding="utf-8") as file:
    rows = json.load(file)
counts = {"уақыт": 0, "орын": 0, "белгісіз": 0}
for row in rows:
    label = row["label"]
    if label in counts:
        counts[label] += 1
    else:
        print("Қате белгі:", label)
print("Уақыт:", counts["уақыт"])
print("Орын:", counts["орын"])
print("Белгісіз:", counts["белгісіз"])
```

[Файлы шага](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-21).

## Как работает код

`counts` хранит три счётчика. `for row in rows` проходит карточки, `row["label"]` берёт человеческую метку. `label in counts` проверяет, есть ли такая метка в разрешённом наборе; `+= 1` прибавляет единицу к прежнему числу. Непонятная метка печатается как ошибка и не попадает в счётчики. Мы ещё не обучаем модель — проверяем качество исходной разметки.

## Опорная карта

Вопрос → человеческая метка → список JSON → проверка допустимости → счётчики 8 / 7 / 4.

## Вспомните и проверьте

Закройте код и назовите три возможные метки. Добавьте вопрос `Сурет нешеде?` с меткой `уақыт`. Подсказка: новую карточку отделяет запятая. Эталон: `Уақыт: 9`, `Орын: 7`, `Белгісіз: 4`. Затем попробуйте метку `уақ` и найдите сообщение `Қате белгі: уақ`. Частая ошибка: считать `белгісіз` отсутствием ответа в каталоге; здесь это метка *вопроса*, каталог фактов проверяется отдельно.
