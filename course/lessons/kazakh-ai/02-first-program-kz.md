# 2-сабақ. Бағдарламаның алғашқы тексерілетін қадамы

## Бұл не үшін керек?

Адам кестеге қарап мәліметті табады. Бағдарламаға нақты әрекет жазу қажет. Әуелі бекітілген бір жазбаны экранға шығарамыз.

**Python** — оқу үлгісін жазатын бағдарламалау тілі. **Код** — нұсқаулар жазылған мәтін. **Терминал** — компьютерге пәрмен енгізетін терезе. `python3` пәрмені Python-ды іске қосады; одан кейінгі атау код сақталған файлды көрсетеді.

## Файлға орын дайындаңыз

Python орнатылмаса, оны [ресми беттен](https://www.python.org/downloads/) жүктеңіз. Windows жүйесінде «Бастау» мәзірінен PowerShell терезесін ашып, `py --version` пәрменін орындаңыз: экранда нұсқа нөмірі шығуы керек. `py` табылмаса, орнатқаннан кейін PowerShell терезесін жауып, қайта ашыңыз. macOS не Linux жүйесінде «Терминал» қолданбасын ашып, `python3 --version` пәрменін орындаңыз; ол табылмаса, Python-ды [ресми нұсқаулықпен](https://docs.python.org/3/using/index.html) орнатыңыз. Python 3.10 немесе одан жаңа нұсқа қажет.

Жұмыс үстелінде `ai-course` атты қапшық жасаңыз. Оны файлдарды қарау бағдарламасында ашыңыз. Windows жүйесінде қапшықтың мекенжай жолына `powershell` деп жазып, Enter пернесін басыңыз: терминал осы қапшықта ашылады. macOS пен Linux жүйесінде қапшықты терминалда ашатын мәзір тармағын таңдауға болады. Ондай тармақ болмаса, терминалға `cd ` деп, соңына бос орын қалдырыңыз; қапшық таңбасын терминалға сүйреп апарып, Enter басыңыз. **Ағымдағы қапшық** — пәрмен `club.py` файлын іздейтін орын. Файлды осы қапшыққа UTF-8 мәтіні ретінде сақтаңыз. Windows Блокнотында атауы `club.py.txt` болып кетпеуі үшін файл түрінен «Барлық файлдар» тармағын таңдаңыз.

## Әуелі толық көрініс

`club.py` атты файл жасап, мынаны жазыңыз:

```python
class_name = "Робот құрастыру"
time = "сейсенбі, 16:00"
print(class_name, time)
```

macOS/Linux жүйесінде `python3 club.py`, Windows жүйесінде `py club.py` пәрменін орындаңыз. Күтілетін нәтиже: `Робот құрастыру сейсенбі, 16:00`. «Файл табылмады» деген хабар шықса, файл атауын және ағымдағы қапшықты тексеріңіз.

## Бір де бір қадамды аттап өтпейік

`class_name` және `time` — **айнымалылардың атауы**, яғни мәндерді табуға арналған белгілер. Мұндағы `=` таңбасы оң жақтағы мәнді сол жақтағы атаумен сақтау керек екенін білдіреді; ол теңдеу емес. Қос тырнақша арасындағы мәтін — **жол**, яғни таңбалар тізбегі. `print(...)` ішіндегі жақша экранға шығарылатын мәндерді қоршайды. Үтір екі мәнді ажыратады; экранда олардың арасына бос орын түседі. Бағдарлама әзірге сұрақты талдамайды, тек өзіміз жазған мәліметті көрсетеді.

## Тірек сызба

Код файлы → іске қосу пәрмені → жолдарды жоғарыдан төмен орындау → нәтиже. `атау = мән` мәнді сақтайды; `print(...)` оны көрсетеді.

## Тапсырма және үлгі жауап

Мысалға қарамай, шахматтың бейсенбі күні 15:00-де өтетіні туралы жазба жасаңыз. Іске қоспай тұрып нәтижені болжаңыз. Неліктен бағдарлама сурет сабағының уақытын айта алмайтынын түсіндіріңіз.

**Көмек:** `=` таңбасының оң жағындағы мәндерді ауыстырыңыз. **Үлгі:** `class_name = "Шахмат"`, `time = "бейсенбі, 15:00"`; нәтиже `Шахмат бейсенбі, 15:00`. Сурет сабағы туралы дерек енгізілген жоқ.
