# Урок 5. Собираем ручную модель

## Зачем это нужно

Прежде чем доверить разбор программе, человек должен суметь выполнить его сам. **Ручная модель** — записанные шаги, по которым любой читатель получает тот же результат. Она помогает заметить пропущенное правило.

## Сразу целиком

Наш словарь пока содержит две основы: `үй` («дом») и `мектеп` («школа»). Разрешённые учебные цепочки: основа; основа + часть множества; основа + часть множества + часть места. Знак `+` означает здесь «следующая часть при разборе», а не сложение чисел. Для `үй` используем `-лер`, для `мектеп` — `-тер`; после этих частей добавляем `-де`. Это **маленькая учебная таблица**, а не полное правило казахского языка.

Разбор `үйлерде`: 1) узнаём `үй`; 2) узнаём `-лер`; 3) узнаём `-де`; 4) получаем «в домах». Для `мектептерде` получаем «в школах». Для `кітаптарда` ответ пока «не знаю»: `кітап` отсутствует в нашем словаре, даже если человек понимает слово.

## Опорная карта

Словарь → найти основу → проверить следующую часть → проверить порядок → вывести разбор или «не знаю».

## Восстановите по памяти

Не глядя, перескажите шаги для `үйлерде`. Назовите границу таблицы: какие новые основы и окончания она ещё не знает?

## Задание

Разберите по таблице `үй`, `үйлер`, `мектептерде`, `кітаптарда`, `мектеплерде`. Для каждого укажите результат или первый шаг, на котором проверка останавливается.

**Эталон:** `үй` — дом; `үйлер` — дома; `мектептерде` — в школах; `кітаптарда` — неизвестная основа; `мектеплерде` — после известной основы таблица ждёт `-тер`, а не `-лер`. Последний отказ относится к нашей учебной таблице; подробные звуковые правила будут позже.
