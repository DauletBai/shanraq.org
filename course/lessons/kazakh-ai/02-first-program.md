# Урок 2. Первый проверяемый шаг программы

## Зачем это нужно

Человек может посмотреть в расписание глазами. Программе нужно дать точное действие. Начнём с вывода одной утверждённой записи, чтобы отделить текст программы от её результата.

**Python** — язык, на котором мы напишем учебную модель. **Код** — текст инструкций. **Терминал** — окно, куда вводят команды компьютеру; команда `python3` запускает установленный Python, а имя после неё указывает файл с кодом.

## Подготовьте место для файла

На Windows установите Python с [официальной страницы](https://www.python.org/downloads/), если его ещё нет. Откройте PowerShell через меню «Пуск» и выполните `py --version`: команда должна показать номер версии. Если `py` не находится, закройте и снова откройте PowerShell после установки. На macOS или Linux откройте приложение «Терминал» и выполните `python3 --version`; при отсутствии команды установите Python по [официальной инструкции](https://docs.python.org/3/using/index.html). Нужен Python версии 3.10 или новее.

Создайте на рабочем столе папку `ai-course`. Откройте её в файловом менеджере. На Windows щёлкните по адресной строке папки, введите `powershell` и нажмите Enter: откроется терминал именно в этой папке. На macOS и Linux можно открыть папку в терминале через контекстное меню файлового менеджера; если такого пункта нет, введите `cd ` (с пробелом) в терминале, перетащите значок папки в окно и нажмите Enter. **Текущая папка** — место, где команда ищет файл `club.py`. Сохраните файл в `ai-course` как обычный текст в кодировке UTF-8; в Windows Блокноте выберите «Все файлы», чтобы имя не стало `club.py.txt`.

## Сразу целиком

Создайте файл `club.py` с тремя строками:

```python
class_name = "Робот құрастыру"
time = "сейсенбі, 16:00"
print(class_name, time)
```

Запустите в терминале `python3 club.py` на macOS/Linux или `py club.py` на Windows. Ожидаемый вывод: `Робот құрастыру сейсенбі, 16:00`. Если компьютер пишет, что файл не найден, проверьте его имя и текущую папку. Если версия Python не показалась на подготовительном шаге, сначала завершите установку.

## Разбор без пропусков

`class_name` и `time` — имена **переменных**, то есть меток для значений. Знак `=` здесь означает «сохрани значение справа под именем слева»; это не школьное уравнение. Текст между двойными кавычками — **строка**, набор символов. Скобки в `print(...)` ограничивают то, что нужно вывести. Запятая передаёт `print` два значения; при выводе между ними появляется пробел. Мы ещё не разбираем вопрос и не проверяем источник: программа только печатает то, что мы в неё записали.

## Опорная карта

Файл с кодом → команда запуска → Python выполняет строки сверху вниз → вывод. `имя = значение` сохраняет значение; `print(...)` показывает его.

## Задание и проверка

Закройте пример. Создайте запись для шахмат в четверг в 15:00 и запустите её. Перед запуском предскажите вывод. Затем объясните, почему эта программа пока не может ответить о рисовании.

**Подсказка:** меняются только значения справа от `=`. **Эталон:** `class_name = "Шахмат"`, `time = "бейсенбі, 15:00"`; вывод `Шахмат бейсенбі, 15:00`. Рисование не записано в программе.
