# 19-сабақ. Жауапты үлгі бойынша құрастырамыз

## Бұл не үшін керек?

Анықтама қағазында тұрақты жазу мен тексерілген мәнге арналған бос орын болады. Осындай үлгі жаңа кесте ойлап таппайды: табылған карточканы ғана түсінікті түрде көрсетеді.

## Іске қоспас бұрын

18-қадамдағы карточкаларды қолданамыз. `kind` алдын ала жазылған екі сөйлемнің бірін таңдайды: уақыт немесе орын туралы. `value` белгіленген орынға қойылады. Тырнақша ішіндегі `|` — дереккөз бен күнді бөлетін көрінетін белгі ғана, Python амалы емес.

```json
[
  {"club": "шахмат", "kind": "уақыт", "value": "бейсенбі, 15:00", "source": "club-sheet-01", "checked_on": "2026-09-01"},
  {"club": "шахмат", "kind": "орын", "value": "203-бөлме", "source": "club-sheet-01", "checked_on": "2026-09-01"}
]
```

Жоба түбірінен қадам қалтасына өтіп, бағдарламаны іске қосыңыз:

```text
cd course/kazakh-ai/step-19
python3 answer.py
```

Windows жүйесінде соңғы пәрменнің орнына `py answer.py` деп жазыңыз.

```python
import json

with open("facts.json", encoding="utf-8") as file:
    facts = json.load(file)
club = input("Үйірме: ").lower()
kind = input("Мәлімет түрі: ").lower()
matches = []
for fact in facts:
    if fact["club"] == club and fact["kind"] == kind:
        matches.append(fact)
if len(matches) == 1:
    fact = matches[0]
    if kind == "уақыт":
        print(fact["club"], "үйірмесінің уақыты:", fact["value"])
    elif kind == "орын":
        print(fact["club"], "үйірмесінің орны:", fact["value"])
    print("Дереккөз:", fact["source"], "| тексерілген күні:", fact["checked_on"])
elif len(matches) == 0:
    print("білмеймін: дерек жоқ")
else:
    print("тоқта: бірнеше дерек табылды")
```

## Бағдарлама қалай жұмыс істейді?

Атау `fact["club"]` өрісінен алынады, сондықтан мәтін табылған карточкаға сүйенеді. `print` бөліктердің арасына бос орын қояды. Жазба жоқ не бірнешеу болса, жауап жасалмайды. Әзірше екі бөлек енгізілген кілтке жауап береміз; келесі сабақта оны толық сұрақпен біріктіреміз.

## Тірек сызба

Екі кілт → бір карточка → уақыт/орын сөйлемі + мән → дереккөз + күн.

## Еске түсіріп, тексеріңіз

`шахмат` пен `уақыт` енгізіңіз. Көмек: үлгінің бірінші тармағы алынады. Үлгі жауап: `шахмат үйірмесінің уақыты: бейсенбі, 15:00` және `Дереккөз: club-sheet-01 | тексерілген күні: 2026-09-01`. Орын мәнін өзгертіп, уақыт жауабының өзгермегенін тексеріңіз. Жиі қате: уақытты үлгінің өзіне жазып қою; ол тізімдегі мәліметтен алшақтайды.
