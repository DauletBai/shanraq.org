# Урок 12. Сохраняем несколько возможных значений

## Зачем это нужно

На двери может быть написано «зал»: без дополнительных сведений это может быть спортивный или концертный зал. У казахского `ат` тоже есть разные значения — «лошадь» и «имя». По одному слову нельзя честно выбрать одно. [Словарь казахского литературного языка](https://sozdikqor.kz/sozdik/?id=38) фиксирует оба значения.

## Сначала решение целиком

Будем хранить для одного написания **список кандидатов** — возможных разборов, а не один угаданный ответ. Для `ат` список содержит `жылқы` («лошадь») и `есім` («имя»). Для `үй` пока только `баспана` («жилище»). Это не статистические вероятности: порядок в списке не говорит, что первое значение лучше.

Создайте `meanings.py` в UTF-8 и запустите привычной командой.

```python
analyses = {"ат": ["жылқы", "есім"],
            "үй": ["баспана"]}
word = input("Сөз: ").lower()
if word in analyses:
    print(analyses[word])
else:
    print("білмеймін")
```

[Файл этого шага](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-12) повторяет код урока.

Мы уже знаем словарь `{...}` из урока 8 и список `[...]` из урока 7. Теперь значение одного ключа — целый список. Это похоже на карточку слова с двумя значениями на обороте. `analyses[word]` берёт список по ключу, а `print` показывает его вместе с квадратными скобками и кавычками. Для `ат` получится `['жылқы', 'есім']`. Для `үй` — `['баспана']`. Один элемент тоже хранится в списке: дальше всем словам можно задавать один и тот же вопрос «сколько вариантов?». Для `жол` получим `білмеймін`: этого ключа нет.

Это **не** морфологический разбор всех окончаний и не определение значения по контексту. Мы вручную занесли два слова, чтобы не потерять неоднозначность. Если позже вопрос потребует выбрать между «именем» и «лошадью», модель попросит уточнение или найдёт явное основание; не станет считать первое значение истинным только из-за порядка.

## Опорная карта

Написание → словарь → список возможных значений → сохранить все; нет записи → `білмеймін`. Стрелка не ведёт сразу к единственному ответу.

## Воспроизведение и задание

Закройте код и восстановите запись для `ат` по карте. Объясните, почему `['баспана']` остаётся списком, хотя значение одно. Затем проверьте `АТ`, `үй`, `жол`.

**Задание:** добавьте ключ `"кітап"` с одним значением `"оқу құралы"` («пособие для чтения») и проверьте ввод `кітап`. **Подсказка:** после пары для `үй` нужна запятая; значение помещается в квадратные скобки. **Эталон:** `"кітап": ["оқу құралы"]` внутри словаря; вывод `['оқу құралы']`. **Частая ошибка:** записать два значения `ат` как два одинаковых ключа словаря: второе перезапишет первое. Один ключ должен вести к списку.
