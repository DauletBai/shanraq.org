# Урок 9. Шесть форм одного показателя множества

## Зачем это нужно

В магазине одну и ту же вещь могут упаковать в коробки разных размеров. Значение «несколько» одно, а звучание части слова меняется ради соседних звуков. В казахском языке **показатель множества** имеет варианты `-лар`, `-лер`, `-дар`, `-дер`, `-тар`, `-тер`. Дефис здесь показывает границу частей при объяснении; в обычном слове дефиса нет.

## Сначала таблица

На узком экране проведите таблицу влево, чтобы увидеть последний столбец.

| Основа | Часть множества | Целое слово | Подсказка |
|---|---|---|---|
| `қала` — город | `-лар` | `қалалар` | последняя гласная задняя, конец — гласная |
| `үй` — дом | `-лер` | `үйлер` | последняя гласная передняя, конец — `й` |
| `қалам` — ручка | `-дар` | `қаламдар` | последняя гласная задняя, конец — `м` |
| `тіл` — язык | `-дер` | `тілдер` | последняя гласная передняя, конец — `л` |
| `кітап` — книга | `-тар` | `кітаптар` | последняя гласная задняя, конец — `п` |
| `мектеп` — школа | `-тер` | `мектептер` | последняя гласная передняя, конец — `п` |

**Гласная** — звук, который произносят без преграды во рту. В этих примерах `а` и `ы` — задние, `е`, `і`, `ү` — передние. Последняя гласная выбирает гласный звук окончания, а последний звук основы влияет на начальный согласный. Мы пока **не программируем** все звуковые правила: храним шесть проверенных пар. [Грамматика казахского языка](https://slaviccenters.duke.edu/sites/slaviccenters.duke.edu/files/file-attachments/kazakh-grammar.pdf) описывает этот набор вариантов.

## Работающая таблица

Создайте `plural.py` в UTF-8 и запустите привычной командой.

```python
plural = {"қала": "лар", "үй": "лер", "қалам": "дар",
          "тіл": "дер", "кітап": "тар", "мектеп": "тер"}
word = input("Негіз: ").lower()
if word in plural:
    print(word + plural[word])
else:
    print("білмеймін")
```

Готовый файл этого шага доступен в [папке учебного проекта](https://github.com/DauletBai/shanraq.org/tree/main/course/kazakh-ai/step-09); сначала прочитайте объяснение кода в этом уроке.

Строка словаря перенесена после запятой; четыре пробела перед продолжением нужны только для удобства чтения. Python видит, что фигурная скобка ещё открыта. Здесь `+` **склеивает две строки**, как две бумажные полоски: `"үй" + "лер"` даёт `"үйлер"`. Это не арифметика. Для `үй` выйдет `үйлер`, для `тіл` — `тілдер`; для `дала` будет `білмеймін`, потому что её нет в нашей таблице. Не добавляйте к неизвестной основе окончание наугад.

## Опорная карта и проверка

Известная основа → сохранённый вариант множества → склеить без дефиса → слово. Нет основы → `білмеймін`. Закройте таблицу и назовите по одному примеру для `л`, `д`, `т`; затем проверьте все шесть строк программы.

**Задание:** перед запуском предскажите ответ для `ҚАЛАМ`, `кітап`, `жол`. **Подсказка:** `lower()` уменьшит буквы, но не добавит новых ключей. **Эталон:** `қаламдар`, `кітаптар`, `білмеймін`. **Частая ошибка:** `print("word + plural[word]")` печатает буквальный текст, а не собранное слово.
