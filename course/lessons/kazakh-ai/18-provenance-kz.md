# 18-сабақ. Дереккөз бен тексерілген күн

## Бұл не үшін керек?

Хабарландыру тақтасындағы уақытты қолдану үшін қағазды кім бергенін және қашан тексергенін білу керек. Әр карточкаға осы мәліметті қосамыз.

## Іске қоспас бұрын

Осы қадамның файлдарын алыңыз. Жаңа өрістер: `source` — үйірменің бастапқы парағына берілген шартты белгі, `checked_on` — `жыл-ай-күн` түріндегі тексерілген күн. `2026-09-01` — 2026 жылғы 1 қыркүйек. Нөлдер күн мен айды біркелкі жазуға көмектеседі. `club-sheet-01` — оқу белгісі, шын құжатқа сілтеме емес.

```json
[
  {"club": "шахмат", "kind": "уақыт", "value": "бейсенбі, 15:00", "source": "club-sheet-01", "checked_on": "2026-09-01"},
  {"club": "шахмат", "kind": "орын", "value": "203-бөлме", "source": "club-sheet-01", "checked_on": "2026-09-01"}
]
```

Жоба түбірінен қадам қалтасына өтіп, бағдарламаны іске қосыңыз:

```text
cd course/kazakh-ai/step-18
python3 source.py
```

Windows жүйесінде соңғы пәрменнің орнына `py source.py` деп жазыңыз.

```python
import json

with open("facts.json", encoding="utf-8") as file:
    facts = json.load(file)
club = input("Үйірме: ").lower()
kind = input("Мәлімет түрі: ").lower()
matches = []
for fact in facts:
    if fact["club"] == club and fact["kind"] == kind:
        matches.append(fact)
if len(matches) == 1:
    fact = matches[0]
    print("Дерек:", fact["value"])
    print("Дереккөз:", fact["source"])
    print("Тексерілген күні:", fact["checked_on"])
elif len(matches) == 0:
    print("білмеймін: дерек жоқ")
else:
    print("тоқта: бірнеше дерек табылды")
```

## Бағдарлама қалай жұмыс істейді?

Іздеу өзгермеді. Бір сәйкестік болса, `fact = matches[0]` табылған карточкаға қысқа атау береді. Кейін мәнін, дереккөзін және күнін шығарамыз. Тексерілген күн мәліметтің бүгін де жарамды екенін білдірмейді: жарамдылық шегін 20-сабақта қосамыз. Бастапқы парақта да қате болуы мүмкін; бағдарлама әзірге жауаптың қайдан алынғанын көрсетеді.

## Тірек сызба

Кілттер → бір карточка → мән + шартты дереккөз + тексерілген күн.

## Еске түсіріп, тексеріңіз

`шахмат` пен `орын` енгізіңіз. Көмек: екі өрісі де сәйкес карточканы табыңыз. Үлгі нәтиже: `Дерек: 203-бөлме`, `Дереккөз: club-sheet-01`, `Тексерілген күні: 2026-09-01`. Тек осы карточканың `source` мәнін өзгертіп, жаңа жолды тексеріңіз. Жиі қате: тексерілген күнді жарамдылық мерзімі деп ойлау.
