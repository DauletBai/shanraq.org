# Алғашқы бағдарлама: сандар, жолдар және шығыс

_Лид (summary):_ **Python курсының үшінші сабағы. Дүкен чегінде санаймыз: бірдің орнына екі бөлу, қалдық, дәреже, содан кейін жолдар — қиып алу, ауыстыру, кесу, жабыстыру. Әрі санды мәтін ішіне қоятын f-жолдар: 52 751 740 084 727 ₸ разрядпен, 11,4% үтірден кейінгі бір таңбамен.**

## Не үшін керек

Курста әрі қарай болатынның бәрі — кестелер, графиктер, модельдер — екі нәрсеге сүйенеді: сандарға әрі жолдарға. Дерек жолмен келеді, ал жауап санмен шығады, әрі олардың арасында күнде істелетін жұмыс жатыр.

Қалтаңыздағыдан бастайық: дүкен чегінен.

## Бірден тұтас

Жоба қалтасындағы `chek.py` файлы. Жегу: ортадан `python chek.py`.

```python
"""3-сабақ: сандар, жолдар және шығыс — дүкен чегінің бір жолында.

Жаңа ештеңе орнатудың қажеті жоқ: бұл таза Python. Басында тор белгісі тұрған
жол — түсініктеме, оны машина емес, адам оқиды.
"""

# Чектің бір жолы: атауы, нешеу алынды, данасының бағасы.
LINE = "  Нан ; 2 ; 260  "

print("== сандар")
print("данасының бағасы:", 260)
print("екі дана:", 260 * 2)
print("мыңнан қайырым:", 1000 - 260 * 2)
print("мыңды үшке бөлсек:", 1000 / 3)
print("мыңға неше бүтін нан:", 1000 // 260)
print("қанша теңге қалады:", 1000 % 260)
print("мың квадратта:", 1000 ** 2)

print()
print("== жолдар")
print("қалай келді:", repr(LINE))
print("шеттегі бос орынсыз:", repr(LINE.strip()))
print("кіші әріппен:", LINE.strip().lower())
print("басқа бөлгіш:", LINE.strip().replace(";", "|"))
print("нүктелі үтірмен кесілді:", LINE.strip().split(";"))
print("қайта жабыстырылды:", " / ".join(("нан", "сүт", "май")))

print()
print("== f-жолдар: мәтін ішіндегі сан")
name = "нан"
count = 2
price = 260
print(f"{name}: {count} дана × {price} ₸ = {count * price} ₸")
print(f"жылдық инфляция: {11.3879454675914:.1f}%")
print(f"тиынға дейінгі дана бағасы: {1890 / 3:.2f} ₸")
print(f"елдегі бүкіл ақша массасы: {52751740084726.9:,.0f} ₸")

print()
print("== екі бөлу, әрі бұл екі түрлі нәрсе")
print("кәдімгісі:", 7 / 2, type(7 / 2))
print("бүтіндей:", 7 // 2, type(7 // 2))
```

## Талдау

### `print` — сыртқа шығатын жалғыз терезе

Бағдарлама ештеңе баспай тұрғанда, ол сіз үшін жоқ. `print` үтір арқылы қанша мән болса, сонша қабылдайды әрі олардың арасына бос орын қояды.

`#` таңбасынан басталатын жол — түсініктеме: оны адам оқиды, машина өткізіп жібереді. Файлдың басындағы үш тырнақшадағы жолдар да түсіндірме, бірақ ерекше түрі: бұл — **docstring**, модульдің сипаттамасы, әрі оған функциялар сабағында жетеміз.

### Екі бөлу, әрі оларды шатастыру қымбат

Шығыстың соңғы блогына қараңыз:

```
кәдімгісі: 3.5 <class 'float'>
бүтіндей: 3 <class 'int'>
```

`/` әрқашан бөлшек сан береді, тіпті бүтіндей бөлінгенде де: `4 / 2` — бұл `2.0`, `2` емес. `//` бүтін қайтарады, әрі **төмен қарай дөңгелектейді** — нөлге емес, кіші санға қарай. Оң сандарда бұл «бөлшек бөлігін тастау» сияқты көрінеді: `7 // 2` — `3`. Теріс сандарда ереженің басқа екені байқалады: `-7 // 2` — `-3` емес, `-4`.

Бұл ұсақ нәрсе емес. «Мыңға 260 теңгеден неше нан сыяды» — бұл `1000 // 260`, үшеу, әрі ешқандай «3,84 нан» жоқ. Ал `%` қалғанын береді: `220` теңге. `//` мен `%` қосағы — «нешеуі бүтін, қаншасы қайырым» деген сұрақтың жауабы, әрі ол бетте де, уақытта да керек болады.

`**` — дәрежеге шығару: `1000 ** 2` — миллион.

> **Елестетіп көріңіз.** Нанды адамдарға бөлу. `/` — бухгалтердің жауабы: «үш жарымнан». `//` — үй иесінің жауабы: «үштен, біреуі артық». Екеуі де дұрыс, бірақ дастарқанда екіншісі керек.

### Жол — ондағы жазылған нәрсемен бірдей емес

`repr(LINE)` жолды тырнақшамен әрі барлық бос орнымен көрсетеді: `'  Нан ; 2 ; 260  '`. Бұл маңызды: шеттегі бос орындар көзге көрінбейді, бірақ салыстыруды бұзады әрі санды қоқысы бар мәтінге айналдырады.

Бөтен деректе күнде қолданатын төрт әдіс:

- `.strip()` — шеттегі бос орындарды алып тастау. Ол жолды өзгертпейді, **жаңасын қайтарады**: Python-да жолдар өзгермейді, әрі бұл қателердің бүтін бір тобынан құтқарады;
- `.lower()` — кіші әріпке келтіру, «Нан» мен «нан» бір нәрсеге айналсын деп;
- `.replace(ескісі, жаңасы)` — ауыстыру;
- `.split(бөлгіш)` — бөліктерге кесу. `['Нан ', ' 2 ', ' 260']` қайтты — бұл тізім, әрі ол келесі сабақ. Назар аударыңыз: бөліктердің ішіндегі бос орындар қалды, `split` оларды қозғамайды.

Әрі `.join()` — кері әрекет: `" / ".join(...)` бөліктерді бөлгіш арқылы бір жолға жинайды. Мұндағы рет үйреншікті емес: бөлгіш соңында емес, бірінші тұр.

### f-жолдар: мәтін ішіндегі сан

Санды мәтінге плюспен қосуға болмайды — Python не айтқыңыз келгенін болжамайды. Жақсырақ жолы бар:

```python
print(f"{name}: {count} дана × {price} ₸ = {count * price} ₸")
```

Тырнақшаның алдындағы `f` әрпі мынаны білдіреді: жолдың ішінде фигуралық жақшалар тұра алады, әрі олардың ішіндегісі есептеледі. Ішінде тек ат емес, өрнек те болады: `count * price` сол жерде саналды.

Қос нүктеден кейін санды **қалай** көрсету керегін жазады:

- `{11.3879454675914:.1f}` → `11.4` — үтірден кейін бір таңба;
- `{1890 / 3:.2f}` → `630.00` — ақшаға арналған екі таңба;
- `{52751740084726.9:,.0f}` → `52,751,740,084,727` — разрядтар әрі үтірден кейін бір де таңба жоқ.

Соңғы жол — Қазақстанның бүкіл ақша массасы. Разрядсыз оны оқу мүмкін емес, әрі есептерде бұл бөлек тақырып болады.

## Өз сөзіңізбен айтыңыз

Қарамай, дауыстап немесе қағазға жауап беріңіз. Жауаптар — сабақтың соңында.

1. `7 / 2` `7 // 2`-ден несімен өзгеше — тек нәтижесімен бе?
2. `"  Нан  ".strip()` неге жолдың өзін өзгертпейді?
3. f-жолдағы фигуралық жақшаның ішіндегі қос нүкте не істейді?

## Тапсырма

**Міндетті.** Дүкеннен алған нағыз чегіңізді алыңыз. Мынаны басып шығаратын бағдарлама жазыңыз: бір тауардың сомасы (баға × саны), дөңгелек сомадан қайырым, мың теңгеге ондай тауардың нешеуін алуға болатыны әрі сонда қанша теңге қалатыны. Барлық санды үтірден кейін екі таңбамен f-жолмен шығарыңыз.

**Қалауыңызша.**

- Сол чек 2010 жылы қанша тұратынын санаңыз: әр бағаны 3,48-ге бөліңіз — бірінші сабақтағы көбейткішке.
- Бір санды үш түрлі етіп шығарыңыз: `{x}`, `{x:.2f}`, `{x:,.0f}`. Қайсысы жақсы оқылатынын қараңыз.
- `"  БАҒА ; 1 200,50 ; тг  "` жолын алып, оны `баға;1200.50;тг` түріне келтіріңіз — циклсіз, тек жол әдістерімен.

## Жобада бұл қайда тұрады

Бүгінгі — әрі қарайғының бәрінің іргетасы: бағалар қосылады, индекстер бөлінеді, ал әлемнен келген дерек тазалауды қажет ететін жолмен келеді. Келесі сабақта типтермен айналысамыз: `"260"` мен `260` неге әртүрлі әрі `0.1 + 0.2` неге `0.3`-ке тең емес.

Қарыздар. Жолды кесіп, тізім алдық, бірақ онымен не істеу керегін білмейміз: бұл — тізімдер сабағы. Сандарды бастық, бірақ сақтаған жоқпыз: айнымалылар — келесі сабақ. Әрі чекті талдау әзірге қолмен, жол-жолмен істеледі — циклдерге дейін бес сабақ бар.

## Жауаптар

1. Нәтижесімен де, типімен де: `7 / 2` — бұл `3.5`, жылжымалы нүктелі сан; `7 // 2` — бұл `3`, бүтін. `/` бөлуі тіпті тегіс бөлінгенде де әрқашан `float` қайтарады.
2. Өйткені Python-да жолдар өзгермейді: кез келген әдіс **жаңа** жол қайтарады, ал бастапқысы сол күйінде қалады. Нәтижені сақтау үшін оны меншіктеу керек.
3. Пішімді береді: үтірден кейін неше таңба (`.2f`), разрядтар керек пе (`,`), әрі қалай туралау керек. Санның өзі бұл кезде өзгермейді — тек оның қалай көрсетілгені өзгереді.
