# Переменные и типы: почему «260» и 260 — разные вещи

_Лид (summary):_ **Четвёртый урок курса по Python. Данные из чужого файла приходят текстом, и пока текст не стал числом, складывать его бессмысленно: «260» + «260» даёт 260260. Измерено и главное денежное правило: 0.1 + 0.2 не равно 0.3, а Decimal — равно. Плюс None, истинность строки «0» и разница между == и is.**

## Зачем это нужно

В первом уроке мы взяли числа у Всемирного банка, и они пришли готовыми. В жизни так бывает редко: чаще всего цифры приезжают строкой — из CSV, из формы, из чужого отчёта. И тут выясняется, что `"260"` и `260` для Python — разные вещи, а сложить их одинаково не получится.

Второе, ради чего написан урок: деньги нельзя считать так, как учат в школе. Почему — увидите в третьем блоке вывода.

## Разбор

### Переменная — имя для значения

```python
price_text = "260"
count = 2
```

Знак `=` не «равно», а «присвоить»: справа значение, слева имя, под которым оно теперь известно. Имена пишут маленькими буквами, слова разделяют подчёркиванием — `price_text`, а не `PriceText`. Это не каприз: так пишет весь Python, и чужой код будет читаться привычно.

### Тип — это то, что значение умеет

`type()` показывает, чем значение является:

```
строка: 260 <class 'str'>
число:  260 <class 'int'>
```

На экране они выглядят одинаково. А ведут себя по-разному: `"260" + "260"` даёт `260260` — строки склеились; `260 + 260` даёт `520`.

Никакой ошибки Python при этом не сделал. Он не угадывает, чего вы хотели: у сложения строк есть смысл, и он этим смыслом воспользовался. Ошибку сделали бы вы, если бы не заметили.

Четыре типа, которых хватит надолго: `int` — целое, `float` — с плавающей точкой, `str` — строка, `bool` — истина или ложь. Пятое — `None`, и о нём ниже.

### Превращения и их границы

`int("260")` даёт число. `int("  260  ")` — тоже: пробелы по краям он терпит. А вот `int("260,5")` не сможет:

```
int("260,5") → ValueError — invalid literal for int() with base 10: '260,5'
```

Запятая в качестве десятичного разделителя — обычное дело в казахстанских и российских выгрузках, и Python об этом не знает. Такую строку сначала чинят (`replace(",", ".")`), потом превращают в `float`.

Обратное превращение — `str(260)` — понадобится, когда число надо приклеить к тексту. Хотя чаще для этого берут f-строку из прошлого урока.

> **Образ.** Номер телефона, записанный на бумаге, и сам звонок. На бумаге это текст: его можно переписать, склеить с другим. Позвонить по нему нельзя, пока не наберёшь.

### Почему деньги не считают в `float`

Самое важное в уроке:

```
0.1 + 0.2 = 0.30000000000000004
0.1 + 0.2 == 0.3 → False
```

Это не ошибка Python и не его особенность. `float` хранит число в двоичной системе, а `0.1` в двоичной — бесконечная дробь, как `1/3` в десятичной. Приходится округлять, и на третьем знаке после запятой вылезает хвост.

Для роста цен на графике это неважно. Для денег — важно: тиыны накапливаются, и сумма чека не сходится с итогом в кассе.

Два выхода, оба в выводе:

- **округлять при показе**: `round(0.1 + 0.2, 2)` даёт `0.3`. Годится, когда считаете для человека, а не для бухгалтерии;
- **считать в `Decimal`**: `Decimal("0.1") + Decimal("0.2")` даёт ровно `0.3`, и сравнение возвращает `True`. Обратите внимание: `Decimal` берут **из строки**, а не из `float`, — иначе хвост попадёт внутрь ещё до сложения.

### `True`, `False` и `None`

`bool` — это два значения: `True` и `False`. Но истинность есть у всего, и вот здесь ловушка:

```
bool(0):      False
bool(""):     False
bool("0"):    True ← строка непустая, значит истина
bool(None):   False
```

Строка `"0"` — истина, потому что она не пуста. Данные, пришедшие текстом, лгут здесь особенно охотно: `"0"` из CSV в проверке `if value:` окажется истиной, хотя означает ноль.

`None` — отдельное значение, означающее «ничего нет». Это не ноль и не пустая строка: `None == 0` даёт `False`. Оно понадобится, когда в данных пропуск — а пропуски в реальных таблицах есть всегда.

### `and`, `or`, `not`

Три слова вместо значков — читается как фраза:

```python
print("хватает и не дороже 300 за штуку:", price * count <= budget and price <= 300)
```

`and` — истина, когда истинны оба. `or` — когда хотя бы одно. `not` — переворачивает. Скобки ставьте, когда сомневаетесь: они бесплатны, а разбираться потом дорого.

### `==` сравнивает значения, `is` — объекты

```
first == second: True
first is second: False
```

Два разных списка с одинаковым содержимым **равны**, но это не один и тот же объект. `==` спрашивает «одинаковое ли внутри», `is` — «это одна и та же вещь в памяти».

Практическое правило: `is` используют почти исключительно с `None` — `if value is None:`. Для всего остального `==`. Если написать `if value == None`, оно чаще всего сработает, но так не пишут.

## Куда это встанет в проекте

Сводка получает первое правило работы с чужими данными: пришло текстом — приведи к числу и проверь, что получилось. Дальше мы соберём эти значения в список, а потом в таблицу.

Долги. Мы починили одну строку руками, но в файле их будут тысячи — это циклы. Мы ничего не сохранили — это списки и словари. И мы пока не умеем сказать «если не получилось превратить — пропусти строку»: это урок про исключения.

## Ответы

1. Потому что у сложения строк есть свой смысл — склейка, — и Python им воспользовался. Он не угадывает намерение; следить за типами должен тот, кто пишет.
2. `float` хранит числа в двоичной системе, где `0.1` — бесконечная дробь, поэтому появляется хвост `0.30000000000000004`. Для показа человеку хватает `round`, для денег берут `Decimal`, создавая его из строки.
3. Потому что истинность строки определяется её длиной, а не содержимым: `"0"` не пуста, значит истина. Пустая строка `""` — ложь.
