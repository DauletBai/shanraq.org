# INSERT және параметрлер: шығынды қауіпсіз қосу

_Лид (summary):_ **Операцияларды бір-бірден және топпен қосып, пайдаланушы мәнін SQL кодынан бөлеміз.**

## Бұл не үшін қажет

O'Reilly кітабы сияқты ескертпеде апостроф бар. Жолдарды қосу сұрауды бұзады, ал зиянды енгізу оның мағынасын өзгертуі мүмкін; параметр мәнді бөлек жеткізеді.

> **Бейне.** Сұрау — дайын бланк, параметрлер — оның ұяшықтарындағы мәндер; мән бланкіге жаңа команда қоса алмайды.

## Алдымен тұтас көрініс

```sql
INSERT INTO transactions
    (account_id, category_id, happened_on, amount_tiyn, note)
VALUES
    (1, 2, '2026-09-15', 735000, 'Groceries');
```

## Талдау

INSERT бағандарын әрқашан атаңыз: кестедегі орын тәртібі мағынаны өзгертпейді. Параметр мәнді ғана алмастырады, кесте мен баған атауын алмастырмайды. Идентификаторларды қолданба рұқсат еткен тізімнен таңдаңыз. INSERT OR REPLACE алдымен қайшы жолды өшіреді; саналы жаңарту үшін UPDATE немесе нақты ON CONFLICT қолданыңыз.
