# Терминал және Git: қайталанатын жұмыс нүктесі

_Лид (summary):_ **Каталогта бағдарлауды, commit алдында өзгерісті оқуды және тарихты өшірмей белгілі нұсқаға оралуды үйренеміз.**

> Бұл сабақ нөлден басталады. Бейтаныс сөз сіздің кемшілігіңіз емес: алдымен бейне құрамыз, кейін дәл мағына беріп, содан соң қолданамыз.

## Қай жерде тұрмыз

Қысқа қайталау. Өткен сабақтың тірегі **🏭 жабдық → ☁️ ресурс → 🔁 өзгеріс → 👀 бақылау → 🛟 қалпына келтіру**. Қарамай төрт буынды атаңыз, содан кейін ғана жазбамен салыстырыңыз.

## Сабақ нәтижесі

Каталогта бағдарлауды, commit алдында өзгерісті оқуды және тарихты өшірмей белгілі нұсқаға оралуды үйренеміз. Әр пәрмен нені тексеретінін және қандай ақауды табатынын түсіндіре алмайынша келесі сабаққа өтпеңіз.

## Алдымен таныс бейне

Терминал өте тура түсінетін көмекшімен сөйлесуге ұқсайды: ол қай бөлмеде жұмыс істегіңіз келгенін болжамайды. Git шеберхана журналы секілді: бақылау күйлерін жазып, айырманы көрсетеді. Қауіпті пәрмен алдында «қайдамын?» және «не өзгерді?» деп сұраңыз.

Аналогия ойды бастауға көмектеседі, бірақ технология құрылысын алмастырмайды. Төменде әр сөзді нақтылаймыз.

## Сабақтың тірек сигналы

**📂 қайдамын? → 📝 не өзгерді? → 📸 қай нұсқа? → ✅ қайталауға болады**

Тізбекті солдан оңға оқыңыз. Ол «қай пәрменді жаттаймын?» емес, «келесі қадам неге алдыңғысынан шығады?» дегенге жауап береді.

## Жаңа сөздер қарапайым тілмен

- **Терминал** — Операциялық жүйемен мәтін арқылы сөйлесетін терезе.
- **Shell** — Пәрменді оқып, басқа бағдарламаларды іске қосатын бағдарлама.
- **Репозиторий** — Жоба қалтасы және оның Git тарихы.
- **Commit и SHA** — Сақталған тарих нүктесі және оның бірегей қысқа идентификаторы.

## Асықпай талдаймыз

Каталог, нұсқа және файл айырмасы белгісіз болса, инфрақұрылым пәрмені қауіпті. Git — сиқырлы кері қайтару емес, ниет журналы. Автоматтандыру алдында нүктені бекітіп, diff қарап, шығарылымды нақты commit SHA-мен байланыстырыңыз.

Анықтаманы сөзбе-сөз жаттамаңыз. Себептік байланысты тауып, жоғарыдағы тірекпен қосыңыз.

## Алдымен нәтижені болжаңыз

Іске қоспай тұрып қағазға жазыңыз: не өзгеруі, не сол күйде қалуы және қай output болжамды дәлелдеуі тиіс? Қате болжам да айырманы түсіндіре алсаңыз пайдалы.

## Шағын қадаммен тәжірибе

Пәрмендерді `course/cloud-devops-lab` түбірінен орындаңыз. Пәрмендер оқу ортасына арналған. Серверді не деректі өзгертетін пәрменді іске қоспас бұрын оны толық оқып, ағымдағы қалтаны тексеріңіз. Блокты мағыналық топпен орындаңыз. Әр топтан кейін тоқтап, нәтижені болжаммен салыстырыңыз.

```shell
pwd
git status --short
git diff --check
git rev-parse --short HEAD
git log -1 --format='%h %cs %s'
```

[Жобаның эталон файлдары](https://github.com/DauletBai/shanraq.org/tree/main/course/cloud-devops-lab).

### Бұл тәжірибе нақты не істейді

`pwd` ағымдағы қалтаны көрсетеді. `status` жазылмаған өзгерісті, `diff --check` безендіру қатесін, `rev-parse` нақты нұсқаны, `log` соңғы commit күні мен мағынасын көрсетеді.

## Не шығуы тиіс

- `pwd` репозиторийді көрсетеді.
- `git diff --check` бос орын қатесін таппайды.
- SHA код пен шығарылымды бірмәнді байланыстырады.

## Тірек сызбамен тұтасты жинаңыз

![Тірек сызба 2](/static/course/cloud-devops/map-03-terminal-git-kz.svg)

Төрт блок бойынша жүріп, бүкіл сабақты бір байланысқан әңгімемен түсіндіріңіз.

## Көмексіз жаңғыртыңыз

1. Сызбаны жауып, төрт блокты жатқа сызыңыз.
2. Әр өтуді «себебі» сөзімен түсіндіріңіз.
3. Бір жаңа терминді мәтінді қайталамай анықтаңыз.
4. Нәтижені дәлелдейтін бір сигналды атаңыз.

## Қатені тауып түзетіңіз

Қате: «Git қай өзгеріс жақсы екенін өзі түсініп, бәрін әрқашан қауіпсіз қайтарады». Дұрысы: Git файл тарихын сақтайды; мағына мен қайтару тәсілін адам таңдайды.

## Тапсырма

Енді сол мағынаны өзіңіз жинаңыз. Тірек сызбаға қарауға болады; мақсат — жады емтиханы емес, қайталанатын нәтиже.

**Міндетті.** `set -eu` қолданып, Git репозиторийінен тыс жұмыс істеуден бас тартатын және ағымдағы commit-тің қысқа SHA-сын басатын POSIX sh скриптін жазыңыз. Тек POSIX sh пәрменін не скриптін, нақты кілт пен токенсіз жіберіңіз.

### Дайындық өлшемдері

- Әр іске қосылатын жолды түсінесіз.
- Қайталау күтілетін нәтиже не қауіпсіз түсіндірілген айырма береді.
- Output ішінде нақты key, token және password жоқ.
- Success-ті дәлелдейтін факт көрсете аласыз.

Тексеру өтпесе, күтілген және нақты нәтижені жазып, тіректің бір үзілген буынына оралып қайталаңыз. Қате оқу құқығын алып қоймайды.

**Қалауыңызша.** Бір ықтимал ақауды және оны байқайтын сигналды жазыңыз.
