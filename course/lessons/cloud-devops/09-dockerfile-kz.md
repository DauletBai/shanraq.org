# Dockerfile: шағын, тексерілетін және артық құқығы жоқ жинақ

_Лид (summary):_ **CloudLab-ты multi-stage бейнеге жинап, жинақ кезінде тест өткіземіз және артық құқығы жоқ пайдаланушыны тексереміз.**

## Сабақ нәтижесі

CloudLab-ты multi-stage бейнеге жинап, жинақ кезінде тест өткіземіз және артық құқығы жоқ пайдаланушыны тексереміз. Әр пәрмен нені тексеретінін және қандай ақауды табатынын түсіндіре алмайынша келесі сабаққа өтпеңіз.

## Бұл не үшін маңызды

Multi-stage жинақ компиляторды құрастыру қабатында қалдырып, соңғы бейнеге тек binary файлдарды өткізеді. Бұл шабуыл бетін және өлшемді азайтады. `USER 65532` үдерісті шектейді, ал статикалық healthcheck бейне ішінде shell талап етпейді.

## Тәжірибе

Пәрмендерді `course/cloud-devops-lab` түбірінен орындаңыз. Пәрмендер оқу ортасына арналған. Серверді не деректі өзгертетін пәрменді іске қоспас бұрын оны толық оқып, ағымдағы қалтаны тексеріңіз.

```shell
docker build --build-arg VERSION=lesson-09 -t cloudlab:lesson-09 .
docker image inspect cloudlab:lesson-09 --format 'user={{.Config.User}} size={{.Size}}'
docker run --rm --entrypoint /cloudlab-healthcheck cloudlab:lesson-09 || true
```

[Жобаның эталон файлдары](https://github.com/DauletBai/shanraq.org/tree/main/course/cloud-devops-lab).

## Тапсырма

**Міндетті.** `cloudlab:practice` жинап, бейне пайдаланушысы `0` не бос болса қатемен аяқталатын `docker image inspect` тексеруін жазыңыз. Тек POSIX sh пәрменін не скриптін, нақты кілт пен токенсіз жіберіңіз.

**Қалауыңызша.** Бір ықтимал ақауды және оны байқайтын сигналды жазыңыз.
