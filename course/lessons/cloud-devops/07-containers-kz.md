# Контейнер: шекарасы бар үдеріс, шағын VM емес

_Лид (summary):_ **Алғашқы контейнерді іске қосып, namespace пен өзгермейтін бейнені көреміз және үдерісті виртуалды машинадан ажыратамыз.**

> Бұл сабақ нөлден басталады. Бейтаныс сөз сіздің кемшілігіңіз емес: алдымен бейне құрамыз, кейін дәл мағына беріп, содан соң қолданамыз.

## Қай жерде тұрмыз

Қысқа қайталау. Өткен сабақтың тірегі **адам → мекенжай → сервис → жауап; тірі ≠ дайын ≠ пайдалы**. Қарамай төрт буынды атаңыз, содан кейін ғана жазбамен салыстырыңыз.

## Сабақ нәтижесі

Алғашқы контейнерді іске қосып, namespace пен өзгермейтін бейнені көреміз және үдерісті виртуалды машинадан ажыратамыз. Әр пәрмен нені тексеретінін және қандай ақауды табатынын түсіндіре алмайынша келесі сабаққа өтпеңіз.

## Алдымен таныс бейне

Мейрамхана асүйі ортақ, бірақ әр аспаздың орны, өнімі және шегі бөлек. Контейнер осындай орынға ұқсайды: ортақ Linux ядросын қолданып, шектелген ортаны көреді. Виртуал машина жеке асүйге көбірек ұқсайды.

Аналогия ойды бастауға көмектеседі, бірақ технология құрылысын алмастырмайды. Төменде әр сөзді нақтылаймыз.

## Сабақтың тірек сигналы

**контейнер = үдеріс + шекара; VM = бөлек қонақ ОС**

Тізбекті солдан оңға оқыңыз. Ол «қай пәрменді жаттаймын?» емес, «келесі қадам неге алдыңғысынан шығады?» дегенге жауап береді.

## Жаңа сөздер қарапайым тілмен

- **Контейнер** — Белгіленген файл, желі және шегі бар оқшауланған үдеріс.
- **Образ** — Контейнер іске қосылатын өзгермейтін файл үлгісі.
- **VM** — Өз қонақ операциялық жүйесі бар виртуал компьютер.
- **Namespace** — Үдеріс көретін нәрсені шектейтін Linux механизмі.

## Асықпай талдаймыз

Контейнер хост ядросын бөлісіп, үдеріс, желі және файл көрінісін оқшаулайды. Бейне — үлгі, контейнер — оның іске қосылған данасы. Контейнерді жою маңызды деректі жоғалтумен тең болмауы керек.

Анықтаманы сөзбе-сөз жаттамаңыз. Себептік байланысты тауып, жоғарыдағы тірекпен қосыңыз.

## Алдымен нәтижені болжаңыз

Іске қоспай тұрып қағазға жазыңыз: не өзгеруі, не сол күйде қалуы және қай output болжамды дәлелдеуі тиіс? Қате болжам да айырманы түсіндіре алсаңыз пайдалы.

## Шағын қадаммен тәжірибе

Пәрмендерді `course/cloud-devops-lab` түбірінен орындаңыз. Пәрмендер оқу ортасына арналған. Серверді не деректі өзгертетін пәрменді іске қоспас бұрын оны толық оқып, ағымдағы қалтаны тексеріңіз. Блокты мағыналық топпен орындаңыз. Әр топтан кейін тоқтап, нәтижені болжаммен салыстырыңыз.

```shell
docker version
docker run --rm alpine:3.23 cat /etc/os-release
docker ps -a
docker image ls alpine:3.23
```

[Жобаның эталон файлдары](https://github.com/DauletBai/shanraq.org/tree/main/course/cloud-devops-lab).

### Бұл тәжірибе нақты не істейді

Пәрмендер дайын образды іске қосып, үдерісті іштен және сырттан көрсетіп, контейнерді жояды. PID пен файлды салыстырыңыз: бұл шекарасы бөлек бір үдеріс.

## Не шығуы тиіс

- `--rm` оқу контейнерін аяқталған соң жояды.
- Пәрмен болжамды кодпен аяқталады.
- Нәтижені таза ортада қайталауға болады.

## Тірек сызбамен тұтасты жинаңыз

![Тірек сызба 7](/static/course/cloud-devops/map-07-containers-kz.svg)

Төрт блок бойынша жүріп, бүкіл сабақты бір байланысқан әңгімемен түсіндіріңіз.

## Көмексіз жаңғыртыңыз

1. Сызбаны жауып, төрт блокты жатқа сызыңыз.
2. Әр өтуді «себебі» сөзімен түсіндіріңіз.
3. Бір жаңа терминді мәтінді қайталамай анықтаңыз.
4. Нәтижені дәлелдейтін бір сигналды атаңыз.

## Қатені тауып түзетіңіз

Қате: «Контейнер — жеңіл виртуал машина». Дұрысы: контейнер хост ядросын бөліседі; VM бөлек қонақ ОС іске қосады.

## Тапсырма

Енді сол мағынаны өзіңіз жинаңыз. Тірек сызбаға қарауға болады; мақсат — жады емтиханы емес, қайталанатын нәтиже.

**Міндетті.** `alpine:3.23` контейнерін іске қосып, hostname басатын және шыққан соң контейнерді автоматты жоятын пәрмендерді жазыңыз. Тек POSIX sh пәрменін не скриптін, нақты кілт пен токенсіз жіберіңіз.

### Дайындық өлшемдері

- Әр іске қосылатын жолды түсінесіз.
- Қайталау күтілетін нәтиже не қауіпсіз түсіндірілген айырма береді.
- Output ішінде нақты key, token және password жоқ.
- Success-ті дәлелдейтін факт көрсете аласыз.

Тексеру өтпесе, күтілген және нақты нәтижені жазып, тіректің бір үзілген буынына оралып қайталаңыз. Қате оқу құқығын алып қоймайды.

**Қалауыңызша.** Бір ықтимал ақауды және оны байқайтын сигналды жазыңыз.
