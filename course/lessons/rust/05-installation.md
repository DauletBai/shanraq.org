# Установка Rust и проверка инструментов

_Лид (summary):_ **Урок 5. Проверить установку и выполнить пробную сборку.**


## Зачем это нужно

У мастерской есть несколько инструментов с разными обязанностями. **rustup** устанавливает и выбирает их набор; **rustc** компилирует Rust; **Cargo** организует создание проекта, сборку, запуск и зависимости. Cargo вызывает rustc, а не заменяет его. **Зависимость** — готовая библиотека, которую использует проект; **библиотека** — набор кода для повторного использования. Образ — готовая деталь, но её назначение и ограничения всё равно нужно понимать. **Toolchain** — согласованный набор инструментов определённой версии. **rust-analyzer** помогает редактору подсказками и переходами по коду; он не заменяет проверку программы.

## Установка для вашей ОС

Откройте [официальную страницу установки](https://rust-lang.org/tools/install/). Выберите свою ОС и следуйте показанной там инструкции. Не скачивайте установщик с рекламного сайта. Для Unix страница предлагает команду загрузки и запуска установочного сценария: это программа из интернета, поэтому сверяйте адрес и команду с официальной страницей. Не отключайте проверку сертификатов ради установки.

**Windows.** Используйте rustup-init для своей архитектуры. Если установщик предлагает инструменты Visual Studio C++, следуйте предложенному пути установки; требуются компоненты C++ и Windows SDK. SDK — комплект для создания программ для Windows. Rust использует эти инструменты для заключительной сборки. Полный редактор Visual Studio не является обязательным. Для первого курса выберите обычную Windows-установку, а не смешивайте её с WSL — отдельной Linux-средой внутри Windows.

**macOS.** Установите инструменты командной строки Apple, если их ещё нет: команда xcode-select --install открывает официальный установщик. Затем выполните инструкции rustup. При появлении окна установки закончите его до проверки Rust.

**Linux.** Кроме rustup могут понадобиться системные инструменты сборки. На Ubuntu/Debian их обычно предоставляет пакет build-essential. Установка через sudo apt install build-essential требует прав администратора: sudo запрашивает их, apt управляет пакетами, install означает установить, build-essential — имя пакета. Для другого дистрибутива используйте его инструкцию, а не эту команду вслепую. На учебном или рабочем компьютере без прав попросите администратора установить инструменты; чтение курса не требует обходить ограничения.

**Линкер** объединяет подготовленные части в исполняемую программу — как сборщик готового изделия. Ошибка о linker или link.exe часто означает отсутствие системных инструментов, а не неправильный Rust-код.

## Сразу проверим результат

Закройте и заново откройте терминал после установки. По одной выполните команды; --version просит показать версию:

```sh
rustup --version
rustc --version
cargo --version
```

Каждая должна показать имя и номер версии. Числа могут отличаться от примеров автора. Наши исходники проверены Rust 1.97.0, редакция языка Edition 2024. Разницу версии и редакции объясняет следующий урок. Для начала устанавливайте stable — стабильный канал, а не nightly, предназначенный для экспериментальных возможностей.

Если команда не найдена, сначала откройте новый терминал и проверьте завершение установки. **PATH** — список папок, где оболочка ищет программы, образ — список мест поиска. Это не папка вашего проекта. Не меняйте PATH наугад; проверьте [официальные пояснения rustup](https://rust-lang.github.io/rustup/installation/).

## Редактор и пробная сборка

Установите VS Code с официального сайта code.visualstudio.com, откройте расширения и установите rust-analyzer от rust-lang. **Расширение** добавляет возможности редактору. Пользоваться другим редактором можно, но следующие изображения и действия будут рассчитаны на VS Code.

Номера версий ещё не доказывают работоспособность линкера. Проверим его сейчас. Из rust-learning создайте отдельную пробную программу: cargo new создаёт проект, rust-install-check — имя папки, --edition 2024 выбирает редакцию правил языка, --vcs none отключает создание истории Git. cd входит в папку. cargo run при необходимости собирает и запускает программу. Это проверка установки на готовом примере, а не требование самостоятельно написать незнакомый код.

```sh
cargo new rust-install-check --edition 2024 --vcs none
cd rust-install-check
cargo run
```

Ожидаемый вывод программы — Hello, world! («Привет, мир!»). Compiling и Finished — сообщения инструмента. Если папка уже есть, войдите в неё и повторите только cargo run; не удаляйте свою работу. Не выбирайте имя organizer для пробы: это будущий отдельный проект. После проверки вернитесь в rust-learning через cd .. . В уроках 6–7 подробно разберём созданные файлы и каждый знак исходного кода. Теперь первый блок можно завершить с реально проверенной сборкой.

## Опорная карта

rustup — набор инструментов; Cargo — организация; rustc — компиляция; линкер — объединение; rust-analyzer — подсказки редактору. Образы не означают, что это пять независимых ручных действий при каждом запуске.

## Разминка

1. Предскажите: доказывает ли cargo --version, что проект уже собран?
2. Заполните: подсказки редактору даёт ___, компиляцию выполняет ___.
3. Почините совет «если команда не найдена, перепишите main.rs».

## Задание

**Обязательное.** Сохраните три строки версий в notes.txt, запишите ОС и название оболочки. Ожидаемый результат: команды находятся, вы различаете три инструмента. Завершите описанную выше пробную сборку и запишите её результат.

**На своих данных.** Запишите, где на вашем компьютере установлен редактор.

## Подсказка и эталон

Нужны названия rustup, rustc и cargo с номерами; их номера не обязаны совпадать. Если проблема остаётся, приложите к вопросу ОС, команду и полный текст ошибки. Уберите из текста личные пути при необходимости; пароли и токены не нужны.
