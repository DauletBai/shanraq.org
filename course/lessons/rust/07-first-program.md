# Разбираем первую программу

_Лид (summary):_ **Урок 7. Изменить два сообщения и объяснить каждую строку.**

Редакционный черновик RU. Предварительно: уроки 1–6.

## Зачем это нужно

В предыдущем уроке работал готовый пример. Теперь прочитаем его как понятное поручение. Откройте src/main.rs, замените содержимое целиком, сохраните и выполните cargo run из organizer:

```rust
fn main() {
    println!("Мой органайзер");
    println!("Задача: изучить Rust");
}
```

Вывод программы:

```text
Мой органайзер
Задача: изучить Rust
```

## Разбор без пропущенных знаков

fn начинает объявление **функции**, именованного действия. main — имя функции, с которой начинается выполнение нашей обычной программы. Пустые круглые скобки означают, что здесь нет перечисленных параметров. Фигурные скобки ограничивают **блок**, группу действий. Собственные функции с параметрами подробно появятся в уроке 14; эту входную форму уже нужно узнавать.

println! выводит текст и переводит строку. Знак ! сообщает, что это **макрос**, конструкция, разворачиваемая в код при компиляции. Образ — шаблон подготовки инструкций; это не обычная функция. Писать собственный макрос сейчас не требуется. В круглых скобках находится переданное ему содержимое.

Текст в двойных кавычках — **строковый литерал**, значение, записанное прямо в программе. Кавычки ограничивают текст, но сами не печатаются. Точка с запятой завершает эту **инструкцию**. Отступ в четыре пробела помогает видеть вложенность; фигурные скобки определяют границы независимо от отступа.

Две инструкции выполняются по порядку. Для читателя это два шага, а не одна длинная строка. // начинает однострочный **комментарий**, пояснение для человека до конца строки. Компилятор не исполняет комментарии.

## Ошибка, которую можно понять

Если убрать закрывающую кавычку, компилятор не сможет правильно определить границу текста. Если убрать !, получится другое обращение, а не тот макрос, который мы изучили. Не меняйте сразу десять мест: исправьте одно и повторите cargo check. Команду проверки уже объяснял урок 6.

## Опорная карта

fn main() — вход; { } — блок; println! — вывод; "текст" — литерал; ; — конец инструкции; // — пояснение человеку.

## Разминка

1. Предскажите порядок двух строк до запуска.
2. Заполните пропуск: println___("Текст");
3. Почините отсутствующую закрывающую скобку в своей копии, ориентируясь на первую строку ошибки.
