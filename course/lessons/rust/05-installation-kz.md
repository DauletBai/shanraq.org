# Rust құралдарын орнату және тексеру

_Қысқаша:_ **Орнатуды тексеріп, әр құралдың қызметін ажырату.**

Редакциялық жоба. Алғышарт: алдыңғы сабақтар; 1-сабаққа бағдарламалау тәжірибесі қажет емес.

## Бұл не үшін керек?

Шеберханада әр құралдың өз міндеті бар. **rustup** құралдар жиынтығын орнатады және таңдайды; **rustc** Rust кодын құрастырады; **Cargo** жобаны жасау, құрастыру, іске қосу және тәуелділіктерді басқаруды ұйымдастырады. Cargo rustc құралын алмастырмайды, оны шақырады. **Құралдар жиынтығы** (toolchain) — бір нұсқаға сәйкес келетін құралдар. **rust-analyzer** код өңдегішке көмекші мүмкіндіктер қосады; оның кеңестері бағдарламаны тексерудің орнын баспайды.

## Өз жүйеңізге орнату

[Ресми орнату бетін](https://rust-lang.org/tools/install/) ашып, өз амалдық жүйеңізге арналған нұсқауды орындаңыз. Орнатқышты жарнамалық беттен жүктемеңіз. Unix жүйелеріне арналған бет орнату сценарийін жүктеп орындайтын пәрмен ұсынады. Бұл — интернеттен алынатын бағдарлама: мекен мен пәрменді ресми бетпен салыстырыңыз, орнату үшін куәлікті тексеруді өшірмеңіз.

**Windows.** Құрылғыңыздың сәулетіне арналған rustup-init таңдаңыз. Visual Studio C++ құралдары ұсынылса, орнатқыш көрсеткен жолмен орнатыңыз: C++ құрамдастары мен Windows SDK қажет. SDK — осы ортаға бағдарлама жасауға арналған жинақ. Толық Visual Studio өңдегіші міндетті емес. Алғашқы курс үшін кәдімгі Windows орнатуын таңдаңыз; оны Windows ішіндегі бөлек Linux ортасы — WSL-мен араластырмаңыз.

**macOS.** Apple пәрмен жолы құралдары жоқ болса, xcode-select --install олардың ресми орнатқышын ашады. Оны аяқтаған соң rustup нұсқауларын орындаңыз. Тексеруге кіріспей тұрып орнату терезелеріндегі жұмысты бітіріңіз.

**Linux.** rustup құралынан бөлек жүйелік құрастыру құралдары қажет болуы мүмкін. Ubuntu/Debian жүйесінде оларды әдетте build-essential дестесі береді. sudo apt install build-essential әкімші құқығын талап етеді: sudo сол құқықты сұрайды, apt дестелерді басқарады, install орнатуды білдіреді, build-essential — десте атауы. Басқа таратылымда соның нұсқаулығын қолданыңыз. Құқығыңыз жоқ оқу не жұмыс компьютерінде әкімшіге жүгініңіз; шектеуді айналып өту қажет емес.

**Байланыстырушы** (linker) дайын бөліктерді орындалатын бағдарламаға біріктіреді. Оны бұйымның бөліктерін біріктіретін шеберге ұқсатуға болады. linker не link.exe туралы қате Rust мәтінінің қатесін емес, жүйелік құралдың жоқтығын білдіруі мүмкін.

## Нәтижені тексеру

Орнатудан кейін терминалды жауып, қайта ашыңыз. Мыналарды бір-бірден орындаңыз; --version нұсқа нөмірін сұрайды:

```sh
rustup --version
rustc --version
cargo --version
```

Әрқайсысы құрал атауы мен нұсқасын көрсетуі керек. Нөмірлердің бірдей болуы міндетті емес. Біздің мысалдар Rust 1.97.0 және Edition 2024 арқылы тексеріледі. Нұсқа мен тіл ережесінің редакциясын келесі сабақта ажыратамыз. Бастау үшін stable, яғни тұрақты шығарылым арнасын таңдаңыз; тәжірибелік мүмкіндіктерге арналған nightly әзірге қажет емес.

Пәрмен табылмаса, алдымен терминалды қайта ашып, орнатудың аяқталғанын тексеріңіз. **PATH** — орындалатын пәрмендер ізделетін бумалар тізімі; оны іздеу орындарының тізіміне ұқсатуға болады. Бұл жобаңыздың бумасы емес. Оны ойланбай өзгертпеңіз; [rustup нұсқаулығын](https://rust-lang.github.io/rustup/installation/) қараңыз.

## Өңдегіш және құрастыруды тексеру

VS Code өңдегішін code.visualstudio.com ресми сайтынан орнатыңыз. Оның кеңейтімдерінен rust-lang шығарған rust-analyzer таңдаңыз. **Кеңейтім** өңдегішке мүмкіндік қосады. Басқа өңдегішті қолдануға болады, бірақ суретті нұсқаулар VS Code үшін беріледі.

Нұсқа нөмірінің шығуы байланыстырудың жұмыс істейтінін дәлелдемейді. Оны қазір тексереміз. rust-learning ішінен бөлек сынақ жобасын жасаңыз: cargo new жоба жасайды, rust-install-check — бума атауы, --edition 2024 тіл ережесінің редакциясын таңдайды, --vcs none Git тарихын жасауды өшіреді. cd бумаға кіреді. cargo run қажет болса құрастырып, бағдарламаны іске қосады. Бұл — дайын мысалмен орнатуды тексеру, түсіндірілмеген кодты өзіңіз жазуға арналған тапсырма емес.

```sh
cargo new rust-install-check --edition 2024 --vcs none
cd rust-install-check
cargo run
```

Бағдарламадан Hello, world! («Сәлем, әлем!») жолы күтіледі. Compiling және Finished — құралдың хабарлары. Бума бұрыннан бар болса, оған кіріп, тек cargo run қайталаңыз; жұмысыңызды өшірмеңіз. Сынаққа organizer атауын бермеңіз: кейінгі оқу жобасы бөлек болады. cd .. арқылы rust-learning ішіне қайтыңыз. 6–7 сабақта жасалған файлдар мен бастапқы кодтың әр таңбасын түсіндіреміз. Енді алғашқы топтама нақты құрастыру тексеруімен аяқталады.

## Тірек сызба

rustup — құралдар жиынтығы; Cargo — ұйымдастыру; rustc — құрастыру; байланыстырушы — бөліктерді біріктіру; rust-analyzer — өңдегішке көмек. Әр іске қосқанда бесеуін де қолмен бөлек орындамаймыз.

## Жаттығу

1. Болжаңыз: cargo --version жобаның құрастырылғанын дәлелдей ме?
2. Толықтырыңыз: өңдегішке кеңес беретін құрал — ___, кодты құрастыратын құрал — ___.
3. «Cargo табылмаса, main.rs мәтінін өзгерту керек» деген кеңесті түзетіңіз.

## Тапсырма

**Міндетті.** Үш нұсқа жолын notes.txt файлына сақтап, амалдық жүйеңіз бен қабықша атауын жазыңыз. Күтілетін нәтиже: пәрмендер табылады және құралдардың қызметін ажыратасыз. Жоғарыдағы құрастыру сынағын аяқтап, нәтижесін жазыңыз.

**Өз деректеріңізбен.** Өңдегіштің қайда орнатылғанын жазып алыңыз.

## Көмек және үлгі жауап

Жауапта rustup, rustc, cargo атаулары мен нұсқалары болуы керек; нөмірлердің сәйкес келуі міндетті емес. Көмек сұрағанда жүйе, пәрмен және қатенің толық мәтінін көрсетіңіз. Қажет болса жеке мекендерді алып тастаңыз; құпиясөздер мен қатынау кілттері керек емес.
