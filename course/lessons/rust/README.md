## Проверка редактором

Из корня репозитория: `python3 tools/coursecheck/rustcheck.py`. Нужны Python 3 и Rust 1.97.0 с Cargo и rustfmt; CI использует ту же версию. Проверяются Rust-блоки, эталоны, результаты программ и Cargo-снимки. Уроки 1–5 содержат действия человека и требуют ручного прохождения. Локальные проверки автора не означают проверку установки на всех ОС.

## Политика размещения

По прямому требованию автора уроки не должны попадать в главную ленту статей. На сайте ListPublished исключает записи, связанные с article_series_items; это покрыто TestHomeFeedOmitsCourseLessons. При будущем создании урока связь с курсом и публикация должны происходить в одной транзакции. Не публиковать статью, а затем отдельно добавлять её в курс. Проверить фактическую главную после публикации. Доступ — через каталог курсов, оглавление и соседние уроки.

Записи первой партии созданы атомарно, lesson-slugs.json содержит их привязки. Все 18 языковых страниц сверены с исходниками. Курс обозначен незавершённым; заготовки уроков 6–10 на сайте не опубликованы.
