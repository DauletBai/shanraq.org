## Образ и опорная карта

У кассы есть очередь за услугой и отдельное окно для проблем. В терминале **stdout** — поток обычного результата, **stderr** — поток сообщений об ошибках. **Код завершения** сообщает другой программе, удалось ли действие: 0 означает успех, здесь 2 означает неверную команду. **Карта:** аргументы → выбор команды → stdout или stderr → код завершения. Образ не гарантирует, что текст на экране всегда приходит в порядке двух потоков.

`std::env::args()` даёт слова запуска: первое слово — путь программы; `skip(1)` пропускает его, `collect()` собирает оставшиеся слова в `Vec<String>`. `args.first()` может вернуть отсутствие слова, поэтому результат преобразуется через `map`. `as_str()` даёт представление строки для сопоставления. В `match` `|` означает «любой из перечисленных вариантов», а `if args.len() <= 1` — дополнительное условие. `println!` пишет в stdout, `eprintln!` — в stderr. `std::process::exit(code)` сообщает ненулевой код системе.

## Запустите и разберите

Создайте пустой проект Cargo, вставьте первый Rust блок в `src/main.rs`. `cargo run -- help` передаёт программе `help`: два знака `--` заканчивают аргументы Cargo. `cargo run -- list` выводит пустой список. `cargo run -- mystery` сообщает ошибку; её код 2 относится к запущенной программе. Первый вывод ниже получается от запуска без аргументов. Чтобы проверить именно код программы без влияния Cargo, выполните собранный файл из `target/debug/organizer` с неизвестным словом и проверьте код средствами своей оболочки.

```rust
fn run(args: &[String]) -> i32 {
    match args.first().map(|word| word.as_str()) {
        None | Some("help") | Some("--help") if args.len() <= 1 => {
            println!("Команды: help, list");
            0
        }
        Some("list") if args.len() == 1 => {
            println!("Задач пока нет");
            0
        }
        _ => {
            eprintln!("Неизвестная команда");
            2
        }
    }
}

fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let code = run(&args);
    if code != 0 {
        std::process::exit(code);
    }
}
```
```text
Команды: help, list
```

fn run(args: &[String]) -> i32 {
