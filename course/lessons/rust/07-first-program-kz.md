# Алғашқы бағдарламаны жол-жолымен талдау

_Қысқаша:_ **Шығатын мәтінді өзгертіп, әр жолды түсіндіру.**

Алғышарт: 1–6 сабақ. Басқаша айтылмаса, organizer ішінде жұмыс істеңіз.

## Бұл не үшін керек?

Алдыңғы сабақта дайын мысал жұмыс істеді. Енді оның нұсқауларын түсініп оқимыз. src/main.rs ашып, мазмұнын төмендегі кодпен толық ауыстырыңыз. Сақтап, organizer ішінен cargo run орындаңыз:

```rust
fn main() {
    println!("Менің жоспарлау құралым");
    println!("Іс: Rust тілін үйрену");
}
```

Нәтиже:

```text
Менің жоспарлау құралым
Іс: Rust тілін үйрену
```

## Әр таңбаның міндеті бар

fn атауы бар әрекетті — **функцияны** жариялайды. main — біздің кәдімгі бағдарламамыздың орындалуы басталатын функция атауы. Бос дөңгелек жақшада параметрлер тізімі жоқ. Ирек жақшалар **блокты**, әрекеттер тобын шектейді. Параметрлері бар функцияларды 14-сабақта қарастырамыз; әзірге осы басталу құрылымын тану қажет.

println! мәтін шығарып, келесі жолға өтеді. ! бұл **макрос** екенін білдіреді: ол құрастыру кезінде кодқа айналатын құрылым. Оны нұсқауларды дайындайтын үлгіге ұқсатуға болады. Ол кәдімгі функция емес; өз макросымызды жазу бұл сабаққа кірмейді. Дөңгелек жақшаның ішінде оған берілген мазмұн тұрады.

Қос тырнақшадағы мәтін — **жолдық литерал**, яғни кодта тікелей жазылған мән. Тырнақша мәтін шегін көрсетеді, өзі экранға шықпайды. Нүктелі үтір осы **нұсқауды** аяқтайды. Төрт бос орыннан тұратын шегініс ішкі құрылымды оқуға көмектеседі, ал нақты шекараны ирек жақшалар анықтайды.

Екі нұсқау ретімен орындалып, екі жол шығарады. // сол жолдың соңына дейінгі **түсініктемені** бастайды. Ол адамға арналған, бағдарлама оны орындамайды.

## Түсінуге болатын қате

Жабылатын тырнақшаны алып тастасаңыз, компилятор мәтіннің шегін дұрыс анықтай алмайды. ! алынса, үйренген макросқа жүгіну өзгеріп кетеді. Бірден көп жерді өзгертпей, бір түзетуден кейін 6-сабақтағы cargo check қайталаңыз.

## Тірек сызба

fn main() — басталу; ирек жақша — блок; println! — шығару; тырнақшадағы мәтін — литерал; нүктелі үтір — нұсқаудың соңы; // — адамға түсінік.

## Жаттығу

1. Іске қоспай тұрып екі жолдың шығу ретін болжаңыз.
2. Толықтырыңыз: println___("Мәтін");
3. Көшірмеңіздегі жетіспейтін жабушы ирек жақшаны алғашқы қате хабарына сүйеніп қалпына келтіріңіз.

## Тапсырма

**Міндетті.** Үш жолды осы ретпен шығарыңыз: «Бүгінгі жоспар», «Rust тілін үйрену», «Cargo пәрмендерін қайталау». Үш нұсқау қолданыңыз. Күтілетін нәтиже — тырнақшасыз осы үш жол.

**Өз деректеріңізбен.** Екінші жолға өз ісіңізді жазыңыз.

## Көмек және үлгі жауап

Әр println! бір жолды аяқтайды. Тек тірек сызбаға қарап бағдарламаны қайта жазып көріңіз. Қиын болса, бір жолдан бастаңыз. Жаттығу жауабы: алдымен тақырып, кейін іс; жетіспейтін таңба — !; жабушы жақша main блогын аяқтайды.
