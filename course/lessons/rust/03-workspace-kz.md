# Файлдар, бумалар және жұмыс орны

_Қысқаша:_ **Сақталған файлды оның басқа көшірмесімен шатастырмай табу.**


## Бұл не үшін керек?

Бағдарлама жазбас бұрын өңдеп отырған нәрсемізді дәл табуды үйренеміз. **Файл** — атауы бар деректер. **Бума** файлдарды топтайды. **Файл кеңейтімі** — атаудың .txt немесе .rs сияқты соңғы бөлігі. Мұны бумаларға салынған құжаттарға ұқсатуға болады. Құжат атауын өзгерту оның мазмұнын аудармайды: .txt орнына .rs жазу жай мәтінді дұрыс Rust бағдарламасына айналдырмайды.

## Алдымен тұтас көрініс

Жеке бумаңызда rust-learning деген бума жасаңыз. Жеке бума — пайдаланушының өз орны: Windows жүйесінде көбіне C:\Users\аты, macOS жүйесінде /Users/аты, Linux жүйесінде /home/аты. «аты» орнына өз пайдаланушы атыңыз жазылады. Бұлар көшіріп орындататын пәрмендер емес, мекен үлгілері.

Оның ішінде notes.txt мәтіндік файлын жасап, мына жолды жазыңыз:

```text
Менің жобам — жеке жоспарлау құралы. Алғашқы ісім: Rust тілін үйрену.
```

Word құжатын емес, жай мәтін өңдегішті пайдаланыңыз. Windows жүйесінде Notepad жарайды; macOS жүйесіндегі TextEdit ішінде жай мәтін күйін таңдаңыз; Linux жүйесінде орнатылған мәтін өңдегішті қолданыңыз. Код жазатын өңдегішті 5-сабақта баптаймыз.

Файлды UTF-8 түрінде сақтаңыз. Бұл — қазақ және басқа тілдердің мәтінін байттармен көрсету тәсілі. Байтты кейін түсіндіреміз; әзірге сақтау терезесі сұраса, UTF-8 таңдаңыз.

## Жол — файлдың мекені

**Абсолютті жол** файлдық жүйенің түбірінен не дискіден басталып, толық орынды көрсетеді. **Салыстырмалы жол** ағымдағы бумадан басталады. Бірін толық үй мекенжайына, екіншісін «көрші бөлме» деген нұсқауға ұқсатуға болады. Екіншісін түсіну үшін қайда тұрғаныңызды білу қажет.

rust-learning ішіндегі notes.txt — салыстырмалы жол. Әртүрлі бумадағы екі notes.txt — екі бөлек файл. Windows жүйесіндегі файл шолғыштың «Көрініс» бөлігінен кеңейтімдерді көрсетуді қосыңыз; бөлім атауы жүйе тілі мен нұсқасына байланысты өзгереді. Атау notes.txt.txt болып кетпегенін тексеріңіз. Басқа жүйелерде толық атауды файл қасиеттерінен көріңіз.

**Сақтау** өзгерістерді файлға жазады. Өңдегіште көрініп тұрған мәтін әлі сақталмаған болуы мүмкін. Файлды жауып, қайта ашып, жолды тексеріңіз — әрекет нәтижесін осылай тексереміз.

## Тірек сызба

Файл: атау және мазмұн. Бума: орналасқан жер. Жол: мекен. Сақтау: өзгерістер файлға жазылды. Кеңейтім мазмұнның дұрыстығын дәлелдемейді.

## Жаттығу

1. Болжаңыз: әртүрлі бумадағы екі notes.txt бір файл ма?
2. Толықтырыңыз: салыстырмалы жол ___ бумаға байланысты.
3. notes.txt.txt атауын бір ғана .txt қалатындай түзетіңіз.

## Тапсырма

**Міндетті.** notes.txt жасаңыз, жоғарыдағы сөйлемді сақтаңыз, жауып, қайта ашыңыз. Толық жолын бөлек жазып алыңыз. Күтілетін нәтиже: сөйлем сақталған және дәл сол файлды қайта таба аласыз.

**Өз деректеріңізбен.** «Менің тапсырмам» жолын қосып, әріптердің дұрыс көрінетінін тексеріңіз.

## Көмек және үлгі жауап

Мәтін жоғалса, жаңа көшірме жасамай тұрып сақтауды және буманы тексеріңіз. Үлгі: rust-learning ішінде бір notes.txt бар; қайта ашқанда екі жол да оқылады. Әр адамның толық жолы әртүрлі болуы қалыпты.

Файл атауын, бумасын және мазмұнын бөлек көрсете алсаңыз, келесі сабаққа дайынсыз.
