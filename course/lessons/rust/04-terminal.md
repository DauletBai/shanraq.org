# Терминал без загадок

_Лид (summary):_ **Урок 4. Перейти в папку с пробелом в имени.**

Редакционный черновик RU. Предварительно: предыдущий урок.

## Зачем это нужно

**Терминал** — окно для текстового взаимодействия. **Оболочка** — программа, которая понимает введённые команды: PowerShell на Windows, обычно zsh на macOS, часто bash на Linux. Образ — окно приёма поручений и диспетчер внутри. Терминал не понимает исходный код Rust вместо компилятора.

## Сразу целиком

Откройте PowerShell из меню Windows или приложение Terminal на macOS/Linux. Перед вводом видно **приглашение**: оно сообщает, что оболочка ждёт команду. Значки вроде $ или PS C:\...> не надо копировать из чужих инструкций. В наших блоках находятся только команды.

Сначала узнаем текущую папку. PowerShell:

```powershell
Get-Location
```

macOS/Linux:

```sh
pwd
```

Текущая папка — точка отсчёта относительных путей. Теперь перейдём в папку прошлого урока. PowerShell:

```powershell
cd "$HOME/rust-learning"
Get-ChildItem
```

macOS/Linux:

```sh
cd "$HOME/rust-learning"
ls
```

cd означает «сменить папку». Следующее за ним значение — **аргумент**, то есть уточнение поручения. $HOME — обозначение домашней папки в этих оболочках; ничего вручную присваивать ему не нужно. Двойные кавычки сохраняют путь одним аргументом, даже если в нём пробелы. Get-ChildItem и ls показывают содержимое: среди файлов должен быть notes.txt.

## Команда и код — разные вещи

Если вставить fn main() в оболочку, она не станет программой Rust. Исходный код мы пишем в файле .rs, а команды инструментам — в терминале. Нажатие Enter отправляет команду. Не добавляйте к ней показанный ниже результат выполнения.

В обычной запущенной терминальной программе Ctrl+C посылает запрос прерывания. Для выхода из самой оболочки есть команда exit; после неё окно или вкладка может закрыться. Эти действия различаются.

Если cd сообщает, что папка не найдена, проверьте имя rust-learning и её расположение из урока 3. Не исправляйте проблему запуском от администратора: неправильный путь не становится правильным от дополнительных прав.

## Опорная карта

Терминал → оболочка → команда + аргументы → действие → новое приглашение. Текущая папка определяет начало относительного пути.

## Разминка

1. Предскажите: сменится ли текущая папка только от открытия файла в редакторе?
2. Заполните: cd получает путь как ___.
3. Почините путь с пробелами: возьмите его целиком в кавычки.

## Задание

**Обязательное.** Перейдите в rust-learning, покажите содержимое, затем выполните cd .. и ещё раз покажите текущую папку. Две точки обозначают родительскую папку. Ожидаемый результат: сначала rust-learning с notes.txt, затем ваша домашняя папка.

**На своих данных.** Создайте через файловый менеджер внутри rust-learning папку «Мои задачи», перейдите в неё командой cd с кавычками и вернитесь через cd .. .

## Подсказка и эталон

Проверяйте положение после каждого перехода командой Get-Location или pwd. Эталон — путь заканчивается на rust-learning до выхода и больше не заканчивается так после cd .. . Буквальные имена пользователя и диска могут отличаться.
