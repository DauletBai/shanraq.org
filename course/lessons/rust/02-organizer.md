# Какой органайзер мы построим

_Лид (summary):_ **Урок 2. Различить демонстрацию будущего и доступную сейчас программу.**


## Зачем это нужно

У строителя есть план дома до первой стены. Нам тоже нужен видимый результат: органайзер хранит задачи и заметки на вашем компьютере. **Запись** — сведения об одном деле; **команда** — поручение программе; **сценарий** — последовательность действий пользователя для достижения цели.

## Сразу целиком

Это макет будущего поведения, а не работающие сегодня команды. Не вводите его в терминал: исполняемой программы organizer у вас ещё нет.

```text
organizer add "Пройти урок Rust"
organizer list
organizer done 1
```

Первая строка просит добавить дело, вторая — показать список, третья — отметить дело с номером 1 выполненным. Английские слова означают «добавить», «список», «готово». Номер позже станет устойчивым идентификатором, а не местом строки на экране.

В финале программа также ищет записи, меняет описание и приоритет, считает статистику и сохраняет данные. Если данных нет, показывает понятное сообщение. Если ввод неверен, объясняет причину и не меняет другие записи.

## По каким ступеням пойдём

Сначала напечатаем сообщение. Затем посчитаем дела, научимся выбирать действия и повторять их. После этого опишем задачу собственным типом, добавим команды и только затем сохранение в файл.

Первоначальные версии демонстрируют отдельные возможности. Они ещё не принимают команды из макета. У интерактивной версии в памяти данные исчезнут при закрытии; в уроках про файлы устраним это ограничение. Это объявлено заранее, чтобы исчезновение не стало неожиданностью.

Сайт, регистрация, облачная синхронизация и напоминания по расписанию в обязательный проект не входят. Полный путь рассчитан на компьютер. С телефона можно читать; локальные сборки и файловые упражнения требуют рабочего места из следующих уроков. Установка требует интернета; обычная работа готового органайзера — нет.

## Опорная карта

Сообщение → данные → действия → команды → сохранение → проверка → выпуск. Каждый шаг использует предыдущий. Готовая картинка показывает направление, но не требует понять весь будущий код сразу.

## Разминка

1. Предскажите: сохранит ли бумажный макет данные на компьютере?
2. Заполните: сценарий — последовательность ___ для достижения ___.
3. Почините требование «при любой ошибке удалить все задачи».

## Задание

**Обязательное.** Запишите сценарий из четырёх шагов: добавить «Пройти урок Rust», увидеть запись, отметить выполненной, увидеть выполненную запись. Добавьте пятый шаг: попытка завершить несуществующую задачу. Ожидайте сообщение об отсутствии и неизменность первой записи.

**На своих данных.** Придумайте задачу с пробелами и казахскими буквами.

## Подсказка и эталон

Для каждого шага укажите действие и наблюдаемый результат. Эталон: после добавления — одна невыполненная запись; после завершения — та же запись выполнена; после неверного номера — всё осталось как было. Новая запись не появляется из одной демонстрационной строки в учебнике.
