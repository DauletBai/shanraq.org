# Пәрмен жолын түсініп қолдану

_Қысқаша:_ **Атауында бос орын бар бумаға өту.**


## Бұл не үшін керек?

**Терминал** — компьютермен мәтін арқылы әрекеттесетін терезе. **Пәрмендік қабықша** сол терезеде енгізілген пәрмендерді талдайды: Windows жүйесінде PowerShell, macOS жүйесінде көбіне zsh, Linux жүйесінде жиі bash қолданылады. Бірін тапсырма қабылдайтын терезеге, екіншісін оны түсініп орындайтын кезекшіге ұқсатуға болады. Терминал Rust бастапқы кодын компилятордың орнына өңдемейді.

## Алдымен тұтас көрініс

Windows мәзірінен PowerShell ашыңыз; macOS не Linux жүйесінде Terminal қолданбасын ашыңыз. **Шақыру белгісі** қабықшаның пәрмен күтіп тұрғанын көрсетеді. $ немесе PS C:\...> сияқты белгілерді көшірмеңіз. Біздің үлгілерде тек орындалатын пәрмендер жазылады.

Алдымен ағымдағы буманы анықтаңыз. PowerShell:

Бірінші пәрмен блогына дейін: PowerShell ішіндегі `Get-Location` және macOS/Linux ішіндегі `pwd` ағымдағы буманы көрсетеді. Әртүрлі қабықшада бір мақсатқа арналған екі атау бар; тек өз жүйеңіздің пәрменін орындаңыз. Кейін `cd` буманы ауыстырады, `$HOME` жеке бумаңыздың мекенін қояды, ал тырнақшалар ішінде бос орын болса да, жолды бір аргумент күйінде сақтайды. `Get-ChildItem` не `ls` буманың ішін көрсетеді. Пәрмен атауынан кейінгі **аргументтер** тапсырманы нақтылайды. `$HOME` мәнін өзіңіз өзгертпеңіз.

```powershell
Get-Location
```

macOS/Linux:

```sh
pwd
```

Ағымдағы бума — салыстырмалы жолдың басталу нүктесі. Енді 3-сабақтағы бумаға өтіп, ішін қараймыз. PowerShell:

```powershell
cd "$HOME/rust-learning"
Get-ChildItem
```

macOS/Linux:

```sh
cd "$HOME/rust-learning"
ls
```

cd буманы ауыстырады. Одан кейінгі мән — **пәрмен аргументі**, яғни тапсырманы нақтылайтын дерек. $HOME осы қабықшаларда жеке бумаңызды білдіреді; оған қолмен жаңа мән бермеңіз. Қос тырнақша жолды, ішінде бос орын болса да, бір аргумент ретінде сақтайды. Get-ChildItem пен ls бума ішін көрсетеді; notes.txt көрінуі керек.

## Пәрмен мен код екі бөлек

Қабықшаға fn main() жазу Rust бағдарламасын жасамайды. Бастапқы код .rs файлына, құралға берілетін пәрмен терминалға жазылады. Enter пәрменді жібереді. Үлгінің астында көрсетілген нәтижені пәрменнің жалғасы ретінде қоспаңыз.

Терминалда жұмыс істеп тұрған кәдімгі бағдарламаға Ctrl+C басу үзу сұрауын жібереді. exit пәрмені қабықшаның өзінен шығарады; терезе не қойынды жабылуы мүмкін. Бұл екі әрекетті шатастырмаңыз.

cd буманы таппаса, rust-learning атауын және 3-сабақтағы орнын тексеріңіз. Әкімші құқығымен іске қосу қате мекенді түземейді.

## Тірек сызба

Терминал → қабықша → пәрмен және аргументтер → әрекет → шақыру белгісі. Ағымдағы бума салыстырмалы жолдың қайдан басталатынын анықтайды.

## Жаттығу

1. Болжаңыз: өңдегіште файл ашылса, қабықшаның ағымдағы бумасы міндетті түрде өзгере ме?
2. Толықтырыңыз: cd жолды ___ ретінде алады.
3. Бос орны бар жолды тұтас қос тырнақшаға алып түзетіңіз.

## Тапсырма

`cd ..` жоғарғы деңгейдегі бумаға өтеді: қос нүкте `..` ағымдағы буманың ата-анасын білдіреді. Тапсырмада осыны қолданасыз.

**Міндетті.** rust-learning бумасына кіріп, ішін көрсетіңіз. Содан кейін cd .. орындап, ағымдағы буманы қайта көрсетіңіз. Екі нүкте жоғарғы деңгейдегі буманы білдіреді. Күтілетін нәтиже: алдымен notes.txt бар rust-learning, кейін жеке бумаңыз.

**Өз деректеріңізбен.** Файл шолғыш арқылы rust-learning ішінде «Менің істерім» бумасын жасаңыз, жолды тырнақшаға алып оған өтіңіз, cd .. арқылы қайтыңыз.

## Көмек және үлгі жауап

Әр ауысудан кейін Get-Location не pwd арқылы орныңызды тексеріңіз. Шыққанға дейін жол rust-learning деп аяқталады, шыққаннан кейін олай аяқталмайды. Пайдаланушы мен диск атауы әртүрлі болуы мүмкін.

Өз жүйеңіздің нұсқауларын ғана орындап, пәрменді нәтижеден ажыратсаңыз, әрі қарай өтіңіз.
