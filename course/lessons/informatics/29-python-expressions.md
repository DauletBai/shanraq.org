## Ситуация и вопрос

Помощник должен напоминать, если задача не выполнена и осталось от нуля до двух дней. Ученик написал одно длинное выражение и получил неожиданное `True`. Что в нём сравнивается сначала? Вместо угадывания разложим правило на отдельные вопросы, как делали с бумажными карточками.

## Новые слова без пропусков

**Выражение** вычисляет значение: `days + 1` даёт число, `days <= 2` — логический ответ. **Оператор** задаёт действие: `+`, `<=`, `and`, `not`. **Операнды** — значения, над которыми оно выполняется. **Приоритет** определяет порядок: умножение раньше сложения; скобки делают замысел явным. `and` требует истинности обеих частей; `not done` меняет логический ответ. **Цепочка сравнений** `0 <= days <= 2` включает оба края. Python не склеивает строку `"2"` с числом 1 в арифметическом сложении — тип надо преобразовать заранее.

## Опорный сигнал

Вход → проверка правила → изменение состояния → наблюдаемый результат. Покажите пальцем, на каком шаге программа читает данные, где сравнивает их с договором и где только сообщает результат. Если шага не видно на схеме, найдите его в коде и добавьте в собственную трассу.

## Разбираем шаг за шагом

Проверьте `done=False, days=2`: `not done` даёт `True`, диапазон `0 <= 2 <= 2` тоже `True`, значит всё выражение `True`. Поменяйте только `days` на −1: левая граница станет ложной. Затем поставьте `done=True`: даже при двух днях напоминание не требуется. Во второй строке примера сначала умножается `3 * 4`, затем прибавляется 2: ответ 14, а не 20. Нарисуйте две маленькие таблицы до запуска.

## Предскажите и проверьте

Закройте блок с выводом. По строкам проследите значения имён и напишите точный ожидаемый текст, включая регистр и порядок строк. Только затем выполните код из каталога `step-03` командой `python3` и сравните посимвольно. Поменяйте один вход; до запуска запишите новый прогноз. Если результат отличается, найдите первую строку расхождения, а не подгоняйте ответ задним числом.

```python
days = 2
limit = 2
print(days + 1)
print(days <= limit)
```

## Ожидаемый вывод

```text

True
```

## Поймайте ошибку

Выражение `days <= 2` случайно включает −1: это уже просроченная задача, а не будущая. Исправьте, добавив нижнюю границу `0 <= days`. Выражение здесь ещё не обрабатывает отсутствие срока `None`; смешивать `None` с числом в сравнении нельзя. Сначала проверяйте, есть ли число.

## Перенос в новую ситуацию
