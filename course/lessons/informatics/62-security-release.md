# Выпуск 1.3: защищённый помощник и восстановление

_Лид (summary):_ **Вы передаёте помощника однокласснику.**

## Где мы на карте

Урок 62 из 72. Блок «Цифровая безопасность» (55–62). Мы продолжаем локального помощника с тремя вымышленными задачами. Каждая мера имеет конкретную границу: учебная версия не становится готовым публичным сервисом.

![Выпуск 1.3: защищённый помощник и восстановление](/static/course/informatics/map-62-security-release-ru.svg)

## Ситуация и вопрос

Вы передаёте помощника однокласснику. Он должен суметь открыть страницу, получить тот же отчёт и восстановить испорченную учебную копию без ваших устных подсказок. Это и есть проверка выпуска 1.3.

## Новые слова без пропусков

**Контрольная точка** — конкретный код, данные, команды и ожидаемый результат. **Восстановление** возвращает рабочую копию из проверенного экземпляра. **План угроз** объясняет, от чего защищаем и что остаётся вне защиты. **Риск остатка** — возможность проблемы после выбранных мер.

## Опорный сигнал

Прочитайте три клетки схемы слева направо, затем закройте третью. Назовите вход и действие в каждой клетке; предскажите, чем закончится путь и какой наблюдаемый факт подтвердит ответ. Сравните рисунок с файлом проекта или контрольным примером. Если число на схеме не получается из данных, исправьте схему, а не данные под красивую картинку.

## Разбираем шаг за шагом

В папке `step-06` выполните `python3 data_assistant.py init`, затем `python3 security_assistant.py verify assistant.db`: получите `tasks=3 sessions=4`. Сделайте резервную копию, восстановите её в новый файл и сравните отчёт 45/0/25. Проверьте веб-страницу на 127.0.0.1: в ней три задачи и прежние статусы `REMIND`, `DONE`, `NO_DATE`. Остановите сервер. База, копия и контрольная сумма не отправляются в репозиторий.

## Предскажите и проверьте

Запишите ожидаемый вывод до запуска кода. Выполните его в указанной папке `step-06` или `step-07`, сравните результат символ за символом и объясните каждую строку. Затем измените один безопасный вымышленный вход и повторите цикл «предсказать — запустить — изменить — объяснить — проверить». Наблюдение на маленьком наборе не превращайте в обещание для реальных людей.

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from data_store import create_database, minutes_report
from security_assistant import backup, restore, verify
with TemporaryDirectory() as folder:
    a, b, c = (Path(folder) / name for name in ("a.db", "b.db", "c.db"))
    create_database(a, "tasks.json", "study_sessions.csv")
    backup(a, b); restore(b, c)
    print(verify(c), minutes_report(c))
```

## Ожидаемый вывод

```text
(3, 4) [('t-01', 45), ('t-02', 0), ('t-03', 25)]
```

## Поймайте ошибку

Выпуск 1.3 защищён только в учебных границах: локальный просмотр, отказ от перезаписи, проверка целостности и восстановление. Здесь нет учётных записей, шифрования резервной копии и защиты публичного сервера. Не размещайте его в интернете.
