## Ситуация и вопрос

Одноклассник просит дать ему помощника без редактора кода. Он хочет увидеть список, добавить срок и отметить задачу. Достаточно ли показать один удачный экран? Нет: программа должна пережить закрытие окна, принять неверный ввод без потери данных и повторить бумажные правила напоминания.

## Новые слова без пропусков

**Интерфейс командной строки (CLI)** принимает текстовую команду и аргументы. **Аргумент** — конкретное значение после команды, например `--today 2026-10-09`. **Парсер** разбирает эти слова и проверяет форму. **Код завершения** 0 означает успех, ненулевой — ошибку для другого инструмента. **Выпуск** — проверенная версия с инструкцией запуска и известными ограничениями. **Доказательство готовности** включает работающий файл, повторяемые тесты, ручной сценарий и объяснение ошибок; красивый экран без проверок не подходит.

## Опорный сигнал

Вход → проверка правила → изменение состояния → наблюдаемый результат. Покажите пальцем, на каком шаге программа читает данные, где сравнивает их с договором и где только сообщает результат. Если шага не видно на схеме, найдите его в коде и добавьте в собственную трассу.

## Разбираем шаг за шагом

Работайте с копией, а не с учебным образцом. (1) `list` показывает три исходные записи. (2) `add t-04 "Жоба жазу" --due 2026-10-11` создаёт новую. (3) `reminders --today 2026-10-09` выдаёт `REMIND` для t-04. (4) `done t-04` сохраняет состояние. (5) Повторный запуск `reminders` выдаёт `DONE`. (6) Недопустимая дата или повторный id возвращают ошибку и не меняют файл. Проверьте каждое наблюдение после нового запуска процесса, иначе вы проверяете только память, а не сохранение.

## Предскажите и проверьте

Закройте блок с выводом. По строкам проследите значения имён и напишите точный ожидаемый текст, включая регистр и порядок строк. Только затем выполните код из каталога `step-03` командой `python3` и сравните посимвольно. Поменяйте один вход; до запуска запишите новый прогноз. Если результат отличается, найдите первую строку расхождения, а не подгоняйте ответ задним числом.

```python
from assistant import main
main(["reminders", "--today", "2026-10-09"])
```

## Ожидаемый вывод

```text
Today: 2026-10-09 (local calendar date)
t-01: REMIND
t-02: DONE
t-03: NO_DATE
```

## Поймайте ошибку

Если задать `--today` только в одном запуске, а другой выполнится завтра, результаты нельзя сравнивать. Зафиксируйте дату в обеих командах. Не публикуйте личные имена, домашние задания других учеников и пароли в `tasks.json`: образец содержит только вымышленные записи.
