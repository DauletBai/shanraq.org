# Алғашқы бағдарлама: күй кодқа айналады

_Лид (summary):_ **Көмекші күйінің алғашқы өзгерісін жұмыс істейтін бағдарламаға айналдырамыз: нәтижені болжап, айнымалы нені сақтайтынын көреміз.**

## Картадағы орнымыз

Бұл 72 сабақтың 27-сі, Python блогының (27–38) бөлігі. Тірек сызба тексерілетін өтулерді көрсетеді. 0.3 қағаз келісіміндегі еске салудың бес нәтижесі мен ойдан алынған бастапқы тапсырмаларды жалғастырамыз.

## Жағдай және сұрақ

Қағаз нұсқада `done` карточкасын `false` күйінен `true` күйіне ауыстырдыңыз. Компьютер карточканы көрмейді, «орындалды» сөзін өзі түсінбейді. Басқа оқушы да дәл сол нәтижені алатындай бірнеше жолды қалай жазамыз? Толық бағдарламаға бірден көшпей, бір айнымалыдан бастаймыз.

## Жаңа сөздерді анық түсінейік

**Бағдарлама** — компьютерге арналған жазылған нұсқаулар тізбегі. **Бастапқы код** — біз оқып, өзгерте алатын мәтін. **Python** — сол мәтінді жазу ережесі бар тіл; `.py` файлы кодты сақтайды. **Интерпретатор** нұсқауларды орындайды. **Айнымалы** — ағымдағы мәнге байланысқан атау: `done = False` жолындағы `=` мән береді, теңдікті сұрамайды. `False` пен `True` — логикалық мәндер, бас әрпі маңызды. `print` мәнді көрсетеді, бірақ оны файлға өздігінен сақтамайды.

## Сабақтың тірек сигналы

Кіріс → ережені тексеру → күйді өзгерту → бақыланатын нәтиже. Бағдарлама қай жерде деректі оқитынын, келісіммен салыстыратынын және қай жерде тек хабарлайтынын көрсетіңіз. Қадам сызбада көрінбесе, кодтан тауып, өз трассаңызға қосыңыз.

## Қадамдап талдаймыз

Әуелі қағазға «бұрын: False, кейін: True» деп жазыңыз. Төмендегі мысалды іске қосып, жолдарды салыстырыңыз. Алғашқы жол `done` атауын `False` мәнімен байланыстырады; бірінші шығару соны көрсетеді. `done = True` жаңа мән береді, екінші шығару оны көреді. Бағдарламаны жауып, қайта қосыңыз: ол тағы `False` мәнінен басталады. Жұмыс кезіндегі күй мен сақталған деректің айырмасы осы.

## Болжаңыз және тексеріңіз

Нәтиже блогын жабыңыз. Атаулар мәнін жол сайын бақылап, әріп регистрі мен жол ретін қоса нақты мәтінді болжаңыз. Содан кейін ғана кодты `step-03` каталогында `python3` арқылы орындап, таңба бойынша салыстырыңыз. Бір кірісті өзгертіп, іске қоспай тұрып жаңа болжам жазыңыз. Айырма болса, жауабыңызды кейін ыңғайламай, алғашқы ауытқыған жолды табыңыз.

```python
done = False
print("Before:", done)
done = True
print("After:", done)
```

## Күтілетін нәтиже

```text
Before: False
After: True
```

## Қатені табыңыз

`false` кіші әріппен жазылса, Python сондай атаулы айнымалыны іздеп, `NameError` береді. `=` орнына `==` қойсаңыз, күй өзгермей, теңдік туралы сұрақ шығады. Қатенің алғашқы түсінікті жолын қарап түзетіңіз де, қайта іске қоспай тұрып нәтижені болжаңыз.

## Жобаға енгізілетін өзгеріс

Жеке жұмыс көшірмеңізде `assistant.py` файлын бастаңыз. Ол әзірге бір ойдан шығарылған тапсырманың күйін ғана көрсетеді, `tasks.json` файлын өзгертпейді. Нәтижені 0.3 қағаз карточкасымен салыстырыңыз.

## Тапсырма және дәлел

Екі ойдан шығарылған тапсырмасы бар `first_state.py` жасаңыз. Алғашқы күйлерін көрсетіп, тек екіншісін орындалды деп белгілеңіз де, екеуін қайта шығарыңыз. Іске қосар алдында төрт күтілетін мәннен тұратын кесте жасаңыз. Бірінші тапсырма өзгермегенін дәлелдеңіз. Бағдарламаны қайта іске қосып, екінші белгі неге сақталмағанын түсіндіріңіз.

## Жаңа жағдайға көшіру

Ойын қадамдарын санайтын `steps = 0`, кейін `steps = 1` айнымалысы да осыған ұқсайды. Санауыштың жаңа мәні экранға сан шығарудан несімен өзгеше? Қайта қосқаннан кейін қадамды сақтау үшін тағы не істеу керек?

## 1, 7 және 30 күннен кейін қайталау

1 күннен кейін бетті ашпай ереже мен бір шекара мысалын еске түсіріңіз. 7 күннен кейін жаңа мысалдағы қатені сыныптасыңызға түсіндіріңіз. 30 күннен кейін жоба тестін қайталап, бұрынғы жазба мен нәтиженің сақталғанын тексеріп, ережені өзге міндетке қолданыңыз.
