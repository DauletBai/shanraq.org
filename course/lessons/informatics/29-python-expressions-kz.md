# Жасырын түрлендірусіз өрнектер

_Лид (summary):_ **Еске салу шартын түсінікті өрнекпен жазып, мәтіннің санға жасырын айналуын күтпей амалдар ретін тексереміз.**

## Картадағы орнымыз

Бұл 72 сабақтың 29-сі, Python блогының (27–38) бөлігі. Тірек сызба тексерілетін өтулерді көрсетеді. 0.3 қағаз келісіміндегі еске салудың бес нәтижесі мен ойдан алынған бастапқы тапсырмаларды жалғастырамыз.

## Жағдай және сұрақ

Көмекші тапсырма орындалмаған әрі нөлден екі күнге дейін қалғанда еске салуы тиіс. Оқушы бір ұзын өрнек жазып, күтпеген `True` алды. Қай салыстыру алдымен орындалады? Болжаудың орнына қағаз карточкадағыдай ережені жеке сұрақтарға бөлеміз.

## Жаңа сөздерді анық түсінейік

**Өрнек** мән есептейді: `days + 1` сан береді, `days <= 2` логикалық жауап береді. **Амал таңбасы** әрекетті көрсетеді: `+`, `<=`, `and`, `not`. **Операндтар** — әрекет жасалатын мәндер. **Басымдық** ретті анықтайды: көбейту қосудан бұрын; жақша ойды анық көрсетеді. `and` екі бөліктің де ақиқат болуын талап етеді; `not done` логикалық мәнді терістейді. `0 <= days <= 2` салыстыру тізбегі екі шетті де қамтиды. Python `"2"` мәтінін 1 санымен арифметикалық қоспайды — әуелі түрлендіру керек.

## Сабақтың тірек сигналы

Кіріс → ережені тексеру → күйді өзгерту → бақыланатын нәтиже. Бағдарлама қай жерде деректі оқитынын, келісіммен салыстыратынын және қай жерде тек хабарлайтынын көрсетіңіз. Қадам сызбада көрінбесе, кодтан тауып, өз трассаңызға қосыңыз.

## Қадамдап талдаймыз

`done=False, days=2` жағдайын қараңыз: `not done` — `True`, `0 <= 2 <= 2` диапазоны да `True`, демек толық өрнек `True`. Тек `days` мәнін −1 етіңіз: сол жақ шек жалған болады. Одан кейін `done=True` қойыңыз: екі күн қалса да еске салу қажет емес. Мысалдың екінші жолында әуелі `3 * 4`, сосын 2 қосылады: жауап 20 емес, 14. Іске қоспай тұрып екі шағын кесте салыңыз.

## Болжаңыз және тексеріңіз

Нәтиже блогын жабыңыз. Атаулар мәнін жол сайын бақылап, әріп регистрі мен жол ретін қоса нақты мәтінді болжаңыз. Содан кейін ғана кодты `step-03` каталогында `python3` арқылы орындап, таңба бойынша салыстырыңыз. Бір кірісті өзгертіп, іске қоспай тұрып жаңа болжам жазыңыз. Айырма болса, жауабыңызды кейін ыңғайламай, алғашқы ауытқыған жолды табыңыз.

```python
days = 2
limit = 2
print(days + 1)
print(days <= limit)
```

## Күтілетін нәтиже

```text
3
True
```

## Қатені табыңыз

`days <= 2` өрнегі −1 мәнін де қабылдайды: ол болашақ емес, мерзімі өткен тапсырма. `0 <= days` төменгі шегін қосыңыз. Бұл өрнек әлі мерзімнің жоқтығын (`None`) өңдемейді; `None` мен санды салыстыруға болмайды. Әуелі сан бар-жоғын тексеріңіз.

## Жобаға енгізілетін өзгеріс

Жобада `not done and 0 <= days <= 2` ережесін тест карточкасындағы санға арналған уақытша тексеру деп жазыңыз. Файлға күн қосылғанша оны сақталған мерзім деп көрсетпеңіз.

## Тапсырма және дәлел

`days = −1, 0, 1, 2, 3` және `done` мәнінің екеуі үшін кесте жасаңыз. Он жауапты әуелі қарындашпен толтырып, содан кейін кодты циклде не қолмен орындаңыз. Әр қате болжамға жауапты өрнектің қай бөлігі өзгерткенін жазыңыз. «Python осылай шешті» деген сөз түсіндірме болмайды.

## Жаңа жағдайға көшіру

Үйірме өтінімді 18:00-ге дейін, сол сәтті қоса қабылдайды. 17:59, 18:00 және 18:01 үшін қандай салыстыру керек? Мұнда минут пен уақыт белдеуі маңызды; күнтізбелік күн туралы өрнек дайын код емес, шек идеясын ғана береді.

## 1, 7 және 30 күннен кейін қайталау

1 күннен кейін бетті ашпай ереже мен бір шекара мысалын еске түсіріңіз. 7 күннен кейін жаңа мысалдағы қатені сыныптасыңызға түсіндіріңіз. 30 күннен кейін жоба тестін қайталап, бұрынғы жазба мен нәтиженің сақталғанын тексеріп, ережені өзге міндетке қолданыңыз.
