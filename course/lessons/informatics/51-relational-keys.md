## Ситуация и вопрос

Если в каждую строку занятий переписывать название «Кітап оқу», ошибка в одном символе создаст будто бы новую задачу. Хранить название один раз и ссылаться на ID надёжнее.

## Новые слова без пропусков

**База данных** — организованное хранилище с правилами чтения и записи. **Реляционная таблица** описывает один вид сущностей: у нас `tasks` и `study_sessions`. **Первичный ключ** уникален в таблице: `task_id` либо `session_id`. **Внешний ключ** `study_sessions.task_id` требует существующей задачи. Связь **один ко многим** означает: одна задача может иметь много занятий; каждое занятие относится к одной задаче. `NULL` в дате означает «дата не назначена», а не пустую строку и не нулевой день.

## Разбираем шаг за шагом

Нарисуйте три задачи слева и четыре занятия справа. Стрелки: `s-01` и `s-02` к `t-01`, `s-03` и `s-04` к `t-03`; у `t-02` стрелок нет. Создайте две таблицы SQLite с первичными ключами и `REFERENCES tasks(task_id)`. Для каждого соединения Python включайте `PRAGMA foreign_keys = ON`: SQLite не следует считать включившим эту проверку автоматически. Попытка вставить `t-99` должна завершиться ошибкой.

## Предскажите и проверьте

Сначала запишите ожидаемый вывод точно, включая порядок строк. Затем выполните код из папки `step-05` и сравните посимвольно. Измените один вход и повторите цикл «предсказать — запустить — объяснить». Пример доказывает только заявленное правило: он не превращает учебные вымышленные данные в измерение реальных людей.

```python
import sqlite3
db = sqlite3.connect(":memory:")
db.execute("PRAGMA foreign_keys = ON")
db.execute("CREATE TABLE tasks (task_id TEXT PRIMARY KEY)")
db.execute("CREATE TABLE sessions (task_id TEXT REFERENCES tasks(task_id))")
print(db.execute("PRAGMA foreign_keys").fetchone()[0])
db.close()
```


## Поймайте ошибку

Не путайте одинаковый `task_id` в двух занятиях с дублем: это разрешённая связь. Дубль здесь — повторный `session_id` или повторная задача с тем же `task_id`. Проверка внешних ключей действует только на соединениях, где она включена.
