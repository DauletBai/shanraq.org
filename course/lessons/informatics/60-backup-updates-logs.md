## Ситуация и вопрос

Представьте запасной ключ от дома: если его никто ни разу не пробовал, он может не открыть замок. Резервная копия полезна только после настоящей проверки восстановления.

## Новые слова без пропусков

**Резервная копия** — отдельный экземпляр данных для восстановления. **Контрольная сумма SHA-256** обнаруживает случайное или намеренное изменение файла, если исходный отпечаток сохранён надёжно. **Журнал событий** сообщает о действиях, но в нём не должны лежать пароли и личные тексты. **Обновление** исправляет известные ошибки; устанавливайте его из проверенного источника и сохраняйте возможность отката.

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from data_store import create_database
from security_assistant import backup, restore, verify
with TemporaryDirectory() as folder:
    db, saved, restored = (Path(folder) / name for name in ("live.db", "backup.db", "restored.db"))
    create_database(db, "tasks.json", "study_sessions.csv")
    backup(db, saved)
    print(verify(db), restore(saved, restored))
```

## Поймайте ошибку

Совпадающий SHA-256 рядом с копией не доказывает авторство: злоумышленник может заменить оба файла. Сам факт создания копии не доказывает, что из неё получится рабочая база. Не записывайте секреты в журналы.
