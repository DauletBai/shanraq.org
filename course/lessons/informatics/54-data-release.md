## Ситуация и вопрос

Одноклассник спрашивает: «Мы перенесли задачи в базу, а старые напоминания сохранились?» Проверяем это не обещанием, а сравнением трёх записей, пяти возможных статусов и браузерной страницы.

## Новые слова без пропусков

**Миграция** переносит данные из прежнего формата в новый по явному правилу. **Транзакция** объединяет изменения: при ошибке набор не должен считаться готовым. **Контрольная точка** — код, исходные файлы, команда сборки и проверяемый результат. **Только чтение** означает, что открытие страницы не меняет файл БД. SQLite хранит задачи и занятия в одном файле на вашем компьютере; это не облако и не общая база всех посетителей сайта.

## Предскажите и проверьте

Сначала запишите ожидаемый вывод точно, включая порядок строк. Затем выполните код из папки `step-05` и сравните посимвольно. Измените один вход и повторите цикл «предсказать — запустить — объяснить». Пример доказывает только заявленное правило: он не превращает учебные вымышленные данные в измерение реальных людей.

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from datetime import date
from data_store import create_database, load_document_from_db
from assistant_core import reminder_status
with TemporaryDirectory() as folder:
    db = Path(folder) / "test.db"
    create_database(db, "tasks.json", "study_sessions.csv")
    for task in load_document_from_db(db)["tasks"]:
        print(task["id"], reminder_status(task, date(2026, 10, 9)))
```

## Ожидаемый вывод

```text
t-02 DONE
t-03 NO_DATE
```

## Поймайте ошибку

Нельзя хранить реальные данные учеников в этом учебном файле или выставлять `http.server` в интернет. SQLite не создаёт авторизацию, резервные копии, права доступа и защиту от чужих запросов автоматически. Отсутствие изменения БД при GET не доказывает безопасность всей будущей системы.
