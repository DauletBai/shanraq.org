## Ситуация и вопрос

До сих пор `done=True` исчезал после закрытия программы. Теперь нужен файл, но запись может оборваться, а старые задачи ещё не имеют даты. Если просто добавить поле и сказать, что так было всегда, ученик не заметит смены договора. Сравним оба формата и проведём запись, повторное чтение и проверку.

## Новые слова без пропусков

**JSON** — текстовый формат с объектами, массивами, строками, числами, `true`, `false` и `null`. В Python им соответствуют словарь, список, `str`, числа, `True`, `False`, `None`. **Сериализация** переводит структуру Python в текст JSON через `json.dump` или `json.dumps`; **разбор** делает обратное через `json.load`. **Версия схемы** сообщает, какие поля допустимы. В 0.2 срока нет; в 1.0 `due_date` хранит ISO-дату либо `null`. **Атомарная замена** записывает новый файл во временный соседний файл и затем заменяет старый; это уменьшает риск частичной записи, но не заменяет резервную копию.

## Разбираем шаг за шагом

Запустите короткий пример с названием «Әліппе оқу»: `ensure_ascii=False` оставляет букву читаемой в тексте JSON. `json.loads` возвращает структуру, а проверка заголовка подтверждает круговой переход. Затем откройте прежний `step-01/data/tasks.json`: там три задачи и версия 0.2. В рабочую копию запишите те же три `id`, названия и `done`, смените версию на 1.0 и задайте каждой `due_date`: реальную вымышленную дату или `null`. Не придумывайте дату для старой записи без требования.

## Предскажите и проверьте

Закройте блок с выводом. По строкам проследите значения имён и напишите точный ожидаемый текст, включая регистр и порядок строк. Только затем выполните код из каталога `step-03` командой `python3` и сравните посимвольно. Поменяйте один вход; до запуска запишите новый прогноз. Если результат отличается, найдите первую строку расхождения, а не подгоняйте ответ задним числом.

```python
import json
item = {"title": "Әліппе оқу", "done": False}
encoded = json.dumps(item, ensure_ascii=False)
print(encoded)
print(json.loads(encoded)["title"])
```

## Ожидаемый вывод

```text
{"title": "Әліппе оқу", "done": false}
Әліппе оқу
```

## Поймайте ошибку

Переименование `tasks.txt` в `tasks.json` не делает содержимое правильным JSON. Одинарные кавычки и `True` внутри файла тоже неверны для JSON: там нужны двойные кавычки и `true`. Проверяйте чтение через `json.load`, структуру полей и повторное чтение после записи, а не только расширение имени.

## Изменение проекта

Функция `load_document` сначала проверяет весь файл, затем отдаёт данные. `save_document` пишет только проверенную версию 1.0 во временный файл и заменяет целевой. Старую 0.2 можно читать, но изменение явно переводит её в 1.0.
