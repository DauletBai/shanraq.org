# От наблюдения к строке данных

_Лид (summary):_ **Одна запись о занятии станет понятной строкой: что измерили, когда и для какой задачи.**

## Где мы на карте

Урок 47 из 72, блок «Данные, таблицы и базы» (47–54). Мы продолжаем помощника 1.1 с тремя вымышленными задачами. В конце блока его записи будут храниться в локальном SQLite, а проверенные правила напоминаний останутся прежними.

![От наблюдения к строке данных](/static/course/informatics/map-47-observations-data-schema-ru.svg)

## Ситуация и вопрос

Вы говорите: «Вчера занимался математикой». Друг записывает 20 минут, а вы помните 25. Что именно наблюдали: время по часам, примерную оценку или воспоминание? Без такого уточнения таблица выглядит точнее реальности.

## Новые слова без пропусков

**Наблюдение** — зафиксированный факт по выбранному правилу. **Строка** — одно наблюдение; **столбец** — одно свойство всех строк. **Схема** задаёт названия и типы столбцов. **Единица измерения** здесь минута. **Источник** показывает, откуда появилась запись: бумажный журнал или учебное приложение. `session_id` отличает одну запись от другой, `task_id` связывает занятие с задачей. Эти ID не являются именами людей.

## Разбираем шаг за шагом

Откройте вымышленный `study_sessions.csv`. В строке `s-01,t-01,2026-10-07,20,paper` одна учебная сессия: задача `t-01`, дата 7 октября, 20 минут, источник — бумага. Запятая разделяет поля; первая строка файла называет столбцы. Сравните со второй записью: у той же задачи другие дата, длительность и источник. Четыре строки — четыре наблюдения, а не четыре ученика. Проверьте, что список `tasks.json` содержит `t-01` и `t-03`; иначе связь была бы выдумана.

## Предскажите и проверьте

Сначала запишите ожидаемый вывод точно, включая порядок строк. Затем выполните код из папки `step-05` и сравните посимвольно. Измените один вход и повторите цикл «предсказать — запустить — объяснить». Пример доказывает только заявленное правило: он не превращает учебные вымышленные данные в измерение реальных людей.

```python
import csv
with open("study_sessions.csv", encoding="utf-8", newline="") as stream:
    first = next(csv.DictReader(stream))
print(first["session_id"], first["task_id"], first["minutes"])
```

## Ожидаемый вывод

```text

```

## Поймайте ошибку

Нельзя называть 20 минут объективным временем, если число восстановлено по памяти. Нельзя смешивать минуты и часы в одном столбце или считать две записи о той же задаче дублями только потому, что `task_id` совпал: отличает их `session_id`.
