# Как диаграмма может солгать правдивыми числами

_Лид (summary):_ **Нарисуем честную диаграмму и заметим, как тот же набор чисел может ввести в заблуждение.**

## Где мы на карте

Урок 50 из 72, блок «Данные, таблицы и базы» (47–54). Мы продолжаем помощника 1.1 с тремя вымышленными задачами. В конце блока его записи будут храниться в локальном SQLite, а проверенные правила напоминаний останутся прежними.

![Как диаграмма может солгать правдивыми числами](/static/course/informatics/map-50-charts-honesty-ru.svg)

## Ситуация и вопрос

По задачам записано 45, 0 и 25 минут. Диаграмма с обрезанной вертикальной осью показывает 45 как огромный скачок по сравнению с 25. Числа не подделаны, но впечатление обманчиво.

## Новые слова без пропусков

**Столбчатая диаграмма** сравнивает категории длиной столбцов; её количественная ось обычно начинается с нуля. **Шкала** превращает число в видимую длину. **Основание оси** — число в начале шкалы. **Выборка** — включённые наблюдения: здесь только четыре вымышленные сессии. **Пропуск** означает отсутствие записи; у `t-02` сумма ноль, потому что сессий нет, а не потому, что задача выполнялась ноль минут. Подпись графика должна назвать единицу, период и источник.

## Разбираем шаг за шагом

Сделайте один символ `#` равным пяти минутам: `t-01` получит девять символов, `t-03` — пять, `t-02` — ни одного. Начало шкалы — ноль. Рядом напишите: «Вымышленные записи, 7–9 октября 2026, минуты, n=4». Теперь мысленно начните ось с 20: 45 и 25 визуально разойдутся намного сильнее. Объясните, почему это меняет восприятие, хотя значения те же.

## Предскажите и проверьте

Сначала запишите ожидаемый вывод точно, включая порядок строк. Затем выполните код из папки `step-05` и сравните посимвольно. Измените один вход и повторите цикл «предсказать — запустить — объяснить». Пример доказывает только заявленное правило: он не превращает учебные вымышленные данные в измерение реальных людей.

```python
totals = [("t-01", 45), ("t-02", 0), ("t-03", 25)]
for task_id, minutes in totals:
    print(task_id, "#" * (minutes // 5) or "(none)")
```

## Ожидаемый вывод

```text
t-01 #########
t-02 (none)
t-03 #####
```
