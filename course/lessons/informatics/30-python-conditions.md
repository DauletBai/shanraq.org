## Ситуация и вопрос

В прошлой теме одно выражение ответило только «да» или «нет». Но помощнику нужны разные сообщения: завершено, срок не задан, просрочено, напомнить или ещё рано. Как выбрать ровно одно сообщение и не пропустить особый случай? На бумаге порядок проверок был частью договора; в Python он станет порядком строк.

## Новые слова без пропусков

**Условие** — выражение с ответом `True` или `False`. **Ветвление** выбирает путь по этому ответу. `if` проверяет первое условие, `elif` — следующее, если предыдущие ложны, `else` принимает всё оставшееся. **Блок** строк с одинаковым отступом выполняется вместе; в Python отступы являются частью синтаксиса, то есть правил записи языка. **Граничный случай** находится прямо на пороге, например два дня. **Взаимоисключающие ответы** означают, что одна задача получает ровно один статус.

## Опорный сигнал

Вход → проверка правила → изменение состояния → наблюдаемый результат. Покажите пальцем, на каком шаге программа читает данные, где сравнивает их с договором и где только сообщает результат. Если шага не видно на схеме, найдите его в коде и добавьте в собственную трассу.

## Разбираем шаг за шагом

Разложите на столе карточки −1, 0, 2, 3. Проведите каждую через ветви примера: −1 останавливается на `days < 0`; 0 и 2 проходят к `days <= 2`; 3 остаётся для `else`. Теперь мысленно поставьте `done=True`: бумажный договор требует `DONE` раньше всех сравнений. В коротком примере ниже `done` ещё не включён, чтобы увидеть сами границы; в проектной функции добавьте его первым условием.

## Предскажите и проверьте

Закройте блок с выводом. По строкам проследите значения имён и напишите точный ожидаемый текст, включая регистр и порядок строк. Только затем выполните код из каталога `step-03` командой `python3` и сравните посимвольно. Поменяйте один вход; до запуска запишите новый прогноз. Если результат отличается, найдите первую строку расхождения, а не подгоняйте ответ задним числом.

```python
for days in (-1, 0, 2, 3):
    if days < 0:
        status = "OVERDUE"
    elif days <= 2:
        status = "REMIND"
    else:
        status = "NOT_YET"
    print(days, status)
```

## Ожидаемый вывод

```text
-1 OVERDUE
0 REMIND
2 REMIND
3 NOT_YET
```

## Поймайте ошибку

Если первым поставить `days <= 2`, просроченное −1 получит `REMIND`. Если написать четыре независимых `if`, несколько условий могут напечатать несколько ответов. Почините порядок и используйте цепочку `if`/`elif`/`else`; затем отдельно обработайте отсутствие даты до сравнения с числом.

## Перенос в новую ситуацию

В автомате продажи билетов статусы могут быть «оплачено», «нет цены», «недостаточно денег», «готово». Какое условие должно проверяться первым, если покупка уже оплачена? Объясните, почему логика первого случая похожа на `done=True`.
