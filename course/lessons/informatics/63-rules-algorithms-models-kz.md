# Ереже, алгоритм және үйретілетін модель

_Қысқаша мазмұн:_ **Көмекші нақты ережемен мерзімді еске салады.**

## Картадағы орнымыз

72 сабақтың 63-сі. «ЖИ және жоба шығарылымы» блогы (63–72). Көмекшінің мерзім ережелері мен жергілікті базасы сақталады; жаңа мүмкіндік тек тапсырма санатын ұсынып, бас тартуға мүмкіндік береді.

![Ереже, алгоритм және үйретілетін модель](/static/course/informatics/map-63-rules-algorithms-models-kz.svg)

## Жағдай және сұрақ

Көмекші нақты ережемен мерзімді еске салады. Енді жаңа тапсырма оқу ма, математика ма деп ұсынсын. Мерзім ережесі өзгермейді: санат ұсынысы еске салуды басқармайды.

## Жоба файлдарын қайдан аламыз

[Бақылау нұсқасының бумасын](https://github.com/DauletBai/shanraq.org/tree/main/course/informatics-assistant/step-07) ашып, Code → Download ZIP арқылы репозиторийді жүктеп, `course/informatics-assistant/step-07` табыңыз. Терминалды осы бумада ашыңыз. `python3 --version` Python нұсқасын көрсетеді; содан кейін сабақтағы тексеруді орындаңыз. Барлық тапсырма атауы ойдан алынған, нақты дерек енгізбеңіз.

## Жаңа сөздерді анық түсінейік

**Алгоритм** — аяқталатын қадамдар тізбегі. **Ереже** адам алдын ала жазған шарт: мысалы, «екі күн не аз қалса, еске сал». **Үйретілетін модель** параметрін мысалдан алады; мұнда олар сөз санағыштары. **Болжам** — жаңа жазба туралы ұсыныс, дәлел емес. `review` санаты сенімді таңдау үшін дерек жетпейтінін білдіреді.

## Сабақтың тірек сигналы

Сұлбаның үш ұяшығын солдан оңға оқып, үшіншісін жабыңыз. Әр ұяшықтың кірісі мен әрекетін айтыңыз; жолдың немен аяқталатынын және қандай байқалатын фактіні тексеретініңізді болжаңыз. Суретті жоба файлымен не бақылау мысалымен салыстырыңыз. Сұлбадағы сан деректен шықпаса, әдемі сурет үшін деректі емес, сұлбаны түзетіңіз.

## Қадамдап талдаймыз

Бір карточкада екі жолды салыстырыңыз. `t-01` үшін дәл мерзім 1.0 нұсқасының ережесімен `REMIND` береді. `Кітап оқу` атауына модельдің сөз санауы `reading` ұсына алады. Атауды белгісіз сөзге өзгертіңіз: модель `review` беруі тиіс, мерзім ережесі бұрынғыша жұмыс істейді. Жіктеуіш сапасын еске салу дұрыстығымен шатастырмаңыз; олар бөлек тексеріледі.

## Болжаңыз және тексеріңіз

Кодты қоспай тұрып күтілетін нәтижені жазыңыз. Оны `step-06` не `step-07` бумасында орындап, таңба бойынша салыстырыңыз және әр жолды түсіндіріңіз. Кейін бір қауіпсіз ойдан алынған кірісті өзгертіп, «болжау — іске қосу — өзгерту — түсіндіру — тексеру» айналымын қайталаңыз. Шағын жиындағы бақылауды нақты адамдарға берілген уәдеге айналдырмаңыз.

```python
from datetime import date
from assistant_core import reminder_status
from classifier import read_examples, train, suggest
rows = read_examples("labelled_tasks.csv")
print(reminder_status({"done": False, "due_date": "2026-10-10"}, date(2026,10,9)))
print(suggest("Кітап оқу", train(rows)))
```

## Қатені табыңыз

`if` қолданатын әр код ЖИ болмайды. Үйренген модель сөз мағынасын адамша түсінбейді. Мерзімнің нақты ережесін статистикалық жорамалмен алмастыруға болмайды.

## Жобаға енгізілетін өзгеріс

`2.1` жобасында база, есеп, еске салу және көшірме сақтау қалады. `labelled_tasks.csv` тек ойдан алынған мысалдарды қамтиды. `classifier.py` `math`, `reading` не `review` кеңесін береді, бірақ шешімді базаға жазбайды. Әр ұсыныс қалдырылған мысалмен салыстырылып, адам қайта қарайды.

## Тапсырма және дәлел

Бір тапсырмаға екі жол салыңыз: мерзім → күй және атау → ұсынылған санат. Кіріс, нәтиже және соңғы шешім иесін көрсетіңіз.

## Жаңа жағдайға көшіру

Термостат белгіленген градустан төменде жылуды қосады, ал жүйе ертеңгі ауа райын болжайды. Қайсысы тұрақты шекпен жұмыс істейді?

## 1, 7 және 30 күннен кейін қайталау

1 күннен кейін сұлбаны жатқа салып, қолданудың бір шегін табыңыз. 7 күннен кейін оны мәтінсіз досыңызға түсіндіріп, блоктың он сұрағының жетеуін шешіңіз; қате жауапты нақты кіріспен талдаңыз. 30 күннен кейін жобаның жаңа көшірмесін ашып, тексеруді қайталап, қағиданы жаңа мысалға көшіріңіз. Кіріс, күтілетін және нақты нәтижесі бар хаттаманы сақтаңыз.
