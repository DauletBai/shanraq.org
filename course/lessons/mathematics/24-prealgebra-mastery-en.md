# Checkpoint: readiness to move from prealgebra to algebra

_Lead (summary):_ **Ten tasks test the meaning of letters, expression transformations, equations, inequalities, coordinates, and transfer.**

## Where we are on the map

This checkpoint shows readiness to use symbols as a language of quantities rather than as mechanical marks.

![Five prealgebra skills and the results of two attempts](/static/course/mathematics/map-24-prealgebra-mastery-en.svg)

## Begin with a familiar image

Memorizing words in a new language is insufficient; you must build new sentences. Algebra likewise uses symbols to model new situations.

## Precise meaning

A score of 8/10 with explained solutions supports moving on. An error points to the earliest weak idea, not merely a rule to memorize.

## The lesson's support signal

`meaning → model → calculation → check → explain in your own words`

quantity → expression → equality/inequality → graphical view → check → transfer

## Worked example

A travel cost may be written with a variable, simplified as an expression, and displayed with coordinates: three views of one model.

## Example with a fading prompt

Change the numbers in the example and repeat the solution without copying its steps. Estimate first, calculate exactly, and check against the original condition.

## Recall without a prompt

1. Define the main idea in one sentence.
2. Rebuild the support signal from memory.
3. Solve the example with different numbers and explain why every step is valid.

## Find and correct the mistake

Calling every letter only an “unknown number” is incomplete: it may represent a quantity with meaning, units, and a valid range.

## Transfer to a new setting

Apply the same relationship to something you can measure yourself. Name the quantities, units, and the boundary within which the model is valid. Check the answer by a second representation or an inverse operation.

## Exercise

**Required.** Complete ten tasks, rebuild any idea below 8/10, and repeat a changed set after seven days.

**With your own data.** Create one everyday example with the same structure and show it in words, a formula, and a check.

**Optional.** Seven days later, change the numbers and repeat without the support map.
