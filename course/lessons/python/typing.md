# Аннотации типов и `mypy`: ошибка до запуска

_Лид (summary):_ **Пятьдесят третий урок курса по Python. Описываем форму данных в сигнатурах, сужаем `None` проверкой и запускаем `mypy`, чтобы несовместимые значения находились до выполнения программы.**

## Зачем это нужно

Python остаётся динамическим: аннотация не запрещает передать строку вместо числа во время выполнения. Но редактор и `mypy` могут проследить путь значения заранее. Особенно полезны типы на границах модулей: в аргументах, результате функции и структуре записи.

## Сразу целиком

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class Observation:
    source_id: str
    year: int
    value: float


def latest(rows: list[Observation]) -> Observation | None:
    if not rows:
        return None
    return max(rows, key=lambda row: row.year)


def label(row: Observation | None) -> str:
    if row is None:
        return "нет данных"
    return f"{row.year}: {row.value:.1f} %"


print(label(latest([Observation("cpi-kz", 2025, 11.4)])))
```

Вывод:

```text
2025: 11.4 %
```

Сигнатура `-> Observation | None` честно сообщает о пустом списке. После `if row is None` анализатор сужает тип: ниже `row` уже точно `Observation`.

## Проверка `mypy`

Установите зафиксированную для курса версию и проверьте файл:

```console
python -m pip install mypy==2.3.1
python -m mypy --strict digest.py
```

Если написать `Observation("cpi-kz", "2025", 11.4)`, проверка укажет, что второй аргумент должен быть `int`. Код при этом Python запустить может — это и есть различие между временем анализа и временем выполнения.

Начните со своих модулей, а не со всех библиотек сразу. Полезная минимальная настройка `pyproject.toml`:

```toml

python_version = "3.12"
strict = true
files = ["sholu", "main.py"]
```

Версия здесь — минимальная версия Python, которую обещает проект, а не случайная версия на компьютере автора.

## Коллекции и понятные псевдонимы

```python
SourceID = str
Evidence = dict[SourceID, float]


def missing(required: set[SourceID], known: Evidence) -> set[SourceID]:
    return required - known.keys()
```

Псевдоним делает намерение видимым, но `SourceID = str` не создаёт новый тип: обычная строка всё ещё подходит. Когда перепутать две строки опасно, позже можно применить `NewType`.

## Не прячьте неизвестное в `Any`

`Any` выключает проверку для значения и распространяется дальше. Ответ JSON действительно неизвестен на границе, поэтому сначала держите его как `object`, проверяйте структуру, а затем создавайте типизированную запись. Не объявляйте весь словарь `dict[str, Any]` только ради тишины.

Аннотация также не проверяет диапазон, единицу измерения или существование `source_id`. Это по-прежнему работа валидации и тестов. Типы дополняют урок 52, а не заменяют его.
