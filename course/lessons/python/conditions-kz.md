# Шарттар: if, elif, else — және жоқ сан

_Лид (summary):_ **Python курсының жетінші сабағы. Сан өздігінен ештеңе айтпайды: 11,4% — көп пе, аз ба? Шарт салыстырады да, жолды таңдайды. Инфляцияда өлшенді: 2025 жылы Қазақстан — 11,4%, әлем — 3,0%. Қоса деректе жұмыс істеудің басты ережесі: қатардағы олқылық — нөл емес, оны `is None` арқылы тексереді.**

## Не үшін керек

Осы уақытқа дейін бағдарлама кез келген санға бірдей есеп жүргізді. Деректегі нағыз жұмыс сандар әртүрлі болғанда, жол соларға тәуелді болғанда басталады: олқылығы бар жылды нөл деп санамай, аттап өту; нормадан жоғары мәнді белгілеу; қоқысы бар қатарды бөлек қою.

Мұның бәрі — бір құрылым. Ол салыстырады да, таңдайды, ішінде үш сөз бар: `if`, `elif`, `else`.

Бүгін дерек туралы курста синтаксистен қымбат тұратын ереже де шығады: **санның болмауы мен нөл — бір нәрсе емес**. Олқылықты нөл деп санаған есеп үнсіз қателеседі, ал сіз ол туралы оқырманнан білесіз.

## Бірден тұтас

`shart.py` файлы. Іске қосу: ортадан `python shart.py`.

```python
"""7-сабақ: шарттар — салыстыруға болатын инфляцияда.

Бір сан салыстыратын нәрсе болмайынша ештеңе білдірмейді. Шарт — сол
салыстырудың өзі, содан кейін бағдарлама бір жолмен жүреді, екіншісімен емес.
"""

# Жылдық инфляция, %. Сандар бірінші сабақтан, Дүниежүзілік банк.
# 2026 жылдың мәні жоқ: жыл бітпеген. Бұл — олқылық, нөл емес.
kz = {2022: 15.0, 2023: 14.5, 2024: 8.7, 2025: 11.4, 2026: None}
world = {2022: 8.1, 2023: 5.8, 2024: 3.0, 2025: 3.0}

here = kz[2025]
there = world[2025]

print("== 2025 жыл")
print(f"Қазақстан: {here} | әлем: {there}")
if here is None:
    print("бұл жылдың саны әлі жоқ")
elif here < there:
    print("әлемдікінен төмен")
elif here < 2 * there:
    print("әлемдікінен жоғары, бірақ екі еседен кем")
else:
    print("әлемдікінен екі есе жоғары немесе одан да көп")

print()
print("== 2026 жыл")
future = kz[2026]
if future is None:
    print("сан әлі жоқ — салыстыратын нәрсе жоқ")
else:
    print("сан бар:", future)

print()
print("== бір шартта екі салыстыру")
if 2.0 <= there < 4.0:
    print(f"әлем: {there} — екі мен төрттің арасында")
if here > there and kz[2024] > world[2024]:
    print("Қазақстан: әлемдікінен қатарынан екінші жыл жоғары")
```

```

== 2026 жыл
сан әлі жоқ — салыстыратын нәрсе жоқ

== бір шартта екі салыстыру

```

## Талдау

### Жақшаның орнына қос нүкте мен шегініс

```python
if here < there:
    print("әлемдікінен төмен")
```

Жол соңындағы қос нүкте «әрі қарай блок» дегенді білдіреді. Блоктың өзі **шегініспен** — төрт бос орынмен — беріледі. Көп тілде бұл үшін фигуралық жақша керек, Python-да олардың рөлін сол жақтағы бос орын атқарады.

Осыдан жаңадан бастағанның көзге түсетін жалғыз қатесі шығады: жол басқа деңгейге кетіп қалады да, сіз ойлаған сәтте емес, басқа кезде орындалады. Редактор төрт бос орынды өзі қояды; оларды табуляциямен араластыруға болмайды, Python бұған бөлек ескерту береді.

> **Елестетіп көріңіз.** Хаттағы азат жол. Сіз «азат жолдың басы», «азат жолдың соңы» деп жазбайсыз — шегініс жасайсыз, әрі ол көрініп тұрады.

### `elif` — «тағы бір if» емес

Сүрінетін айырма біздің шығуымыздан көрінеді. Бірнеше шарт келеді: `11,4` әлемдікінен жоғары, әрі ол одан екі есе де жоғары. Ал басылғаны — бір жол, тізбек бойынша алғаш келгені.

`if — elif — else` тізбегі жоғарыдан төмен тексеріледі де, **алғаш орындалғанында тоқтайды**. Қалғандары мүлде тексерілмейді.

Үш бөлек `if` — мүлде басқа нәрсе:

```
if here > there:        → орындалады
if here > 2 * there:    → бұл да орындалады
```

Бір жолдың орнына екеу. Бұл тілдің қатесі емес, бұл — әртүрлі құрал: тізбек нұсқалардың **біреуін** таңдайды, бөлек `if`-тер бір-біріне тәуелсіз сұрақтарды тексереді.

Соңындағы `else` — «қалған жағдайлардың бәрінде». Ол міндетті емес, бірақ болмаса, бірде-бір шарт келмегенде ештеңе болмайды — мұны да саналы түрде шешу керек.

### Олқылық — нөл емес

Сабақтың ең қымбат жолы:

```python
if future is None:
```

2026 жылдың орнында `None` тұр — инфляция нөл болғандықтан емес, жыл әлі болмағандықтан. Бұл екеуі бөлек нәрсе, әрі есепте екеуі екі түрлі жауап береді.

Мұны дәл `is None` арқылы тексеру керек, былай емес:

```
if future:          → None үшін де, 0.0 үшін де False
```

Типтер сабағынан есіңізде болар: `bool(0.0)` — жалған. Инфляциясы нөл жыл мұндай тексеруден «дерек жоқ» болып өтеді де, есептен үнсіз жоғалады. `is None` дәл керегін сұрайды: мән жоқ па.

Мұндағы `is` сөзі кездейсоқ емес. Ол мәндерді емес, **сол объект пе** дегенді салыстырады, ал `None` Python-да жалғыз данада болады — сондықтан дұрыс тексеру де осы.

### Бір шартта екі салыстыру

```python
if 2.0 <= there < 4.0:
```

Математикадағыдай оқылады: «екіден бастап төртке дейін». Көп тілде былай жазуға болмайды, `there >= 2.0 and there < 4.0` деп құрастыруға тура келеді; Python салыстыру тізбегін тікелей түсінеді де, `there`-ді бір рет есептейді.

### `and`, `or` және тексеру реті

```python
if here > there and kz[2024] > world[2024]:
```

`and` — екеуі де ақиқат болғанда ақиқат; `or` — ең болмаса біреуі ақиқат болғанда; `not` кері аударады.

Одан маңыздысы: **`and` алғаш кездескен жалғанда тоқтайды**, `or` — алғаш кездескен ақиқатта. Оң жағы мүлде есептелмейді. Осыдан курста әрі қарай үнемі керек болатын тәсіл шығады:

```
if value is not None and value > 5:
```

Алдымен санның бар екеніне көз жеткіземіз, содан кейін ғана салыстырамыз. Орнын ауыстырыңыз — олқылықта бағдарлама құлайды, өйткені `None > 5` дегенді салыстыруға болмайды.

### Бір нәрсе неге үш рет жазылған

Бағдарламаға тағы қараңыз: үш блок, әрқайсысында тағы `print`, тағы салыстыру. Жыл үшеу емес, отыз болса, былай жазу мүмкін болмас еді.

Келесі екі сабақтың себебі де осы: **цикл** барлық жылды өзі аралап шығады, ал **функция** салыстыруға ат беріп, оны қанша керек болса, сонша шақыруға мүмкіндік береді. Әзірге қолмен — олардың неден өсіп шығатыны көрінсін.

## Өз сөзіңізбен айтыңыз

Қарамай, дауыстап немесе қағазға жауап беріңіз. Жауаптары — сабақтың соңында.

1. `if — elif — else` тізбегінен неге бір жол басылады, ал үш бөлек `if`-тен — екеу?
2. `if value is None` дегеннің `if not value` дегеннен айырмасы неде, әрі деректе бұл неге маңызды?
3. Сол жағы жалған болып шыққанда `and` не істейді?

## Тапсырма

**Міндетті.** Өзіңіздің үш саныңызды алыңыз — бір тауардың әр дүкендегі бағасын, чектеріңіз бойынша жеке инфляцияңызды немесе өлшеуге келетін кез келген нәрсені. Әрқайсысын орташамен салыстырып, `if — elif — else` тізбегімен басып шығарыңыз: «орташадан арзан», «орташаға жуық» (5% шегінде), «орташадан қымбат». Үш санның бірін `None` қылып, оны бірінші — барлық салыстырудан бұрын — тексеріңіз.

**Қалауыңызша.**

- Тізбекті үш бөлек `if`-пен алмастырып, қанша жол басылатынын қараңыз.
- Оң жағын бірінші қойса құлайтын `and` шартын жазыңыз.
- Өз қатарыңызда тексеріңіз: бес жылдың нешеуі әлемдік инфляциядан жоғары болды?

## Жобада бұл қайда тұрады

Шолу бәрін қатарынан санауды қояды. Осы сабақтан бастап оның талғауы пайда болады: олқылығы бар жыл орташаға кірмейді, нормадан жоғары мән белгіленеді, ал қоқысы бар қатар қорытындыны бұзудың орнына бөлек қойылады.

Қарыздар. Шарттар әзірге әр жылға бір-бірден жазылған — циклмен бұл үш жол болады. Ал «нормадан жоғары» дегенін көзбен шешіп отырмыз: норманың қай жерден өтетіні ешқайда жазылмаған.

## Жауаптар

1. Өйткені тізбек жоғарыдан төмен тексеріледі де, алғаш келген шартта тоқтайды: қалғандары мүлде тексерілмейді. Бөлек `if`-тер — бір-біріне тәуелсіз сұрақтар, әрқайсысы орындалуы мүмкін.
2. `is None` мәннің жоқтығын сұрайды. `not value` `None` үшін де, нөл үшін де, бос жол үшін де ақиқат — инфляциясы нөл жыл мұндай тексеруден «дерек жоқ» болып есептен жоғалады.
3. Ештеңе: оң жағы есептелмейді. Сондықтан `value is not None and value > 5` қауіпсіз, ал кері рет олқылықта құлайды.
