# Айнымалылар мен типтер: «260» мен 260 неге екі басқа нәрсе

_Лид (summary):_ **Python курсының төртінші сабағы. Бөтен файлдан дерек мәтінмен келеді, әрі мәтін санға айналмайынша оны қосудың мағынасы жоқ: «260» + «260» 260260 береді. Ақшаның басты ережесі де өлшенді: 0.1 + 0.2 0.3-ке тең емес, ал Decimal — тең. Қоса None әрі == пен is.**

## Не үшін керек

Бірінші сабақта біз сандарды Дүниежүзілік банктен алдық, әрі олар дайын күйінде келді. Өмірде олай сирек болады: көбіне сандар жолмен келеді — CSV-ден, формадан, бөтен есептен. Сонда `"260"` мен `260` Python үшін екі басқа нәрсе екені, әрі оларды бірдей қосу мүмкін емесі белгілі болады.

Сабақтың жазылуының екінші себебі: ақшаны мектепте үйреткендей санауға болмайды. Неге екенін шығыстың үшінші блогынан көресіз.

## Бірден тұтас

`tipter.py` файлы. Іске қосу: ортадан `python tipter.py`.

Бағдарлама ұзын — алпыс жол. Есте ұстау керегі — бірінші жартысы: жолды санға айналдыру, ақшаны `Decimal`-мен санау. Қалғанын (`None`, ақиқаттық, `is`) бет-жүзінен танып қойса жеткілікті, кездескенде оралуға болады.

```python
"""4-сабақ: айнымалылар мен типтер — жолмен келген сандарда.

CSV-ден, формадан және кәдімгі мәтіндік файлдан мәндер көбіне мәтінмен келеді.
Мәтін санға айналмайынша, оны қосудың мағынасы жоқ: жолдарды қосу күткен
нәрсені бермейді.
"""

from decimal import Decimal

# Айнымалы — мәннің аты. Атты кіші әріппен жазады, сөздерді астыңғы сызықпен
# бөледі: бүкіл Python-да солай қабылданған.
price_text = "260"
count = 2

print("== сырты бірдей, мәні басқа")
print("жол:", price_text, type(price_text))
print("сан:", 260, type(260))
print("жол + жол:", price_text + price_text)
print("сан + сан:", 260 + 260)

print()
print("== мәтінді санға айналдырамыз")
price = int(price_text)
print("int(\"260\"):", price, type(price))
print("бос орындармен де:", int("  260  "))
print("бөлшек:", float("260.5"), type(float("260.5")))
print("қайта мәтінге:", str(price) + " теңге")
print("сома:", price * count, "теңге")

print()
print("== ал мынау айналмайды")
try:
    int("260,5")
except ValueError as err:
    print("int(\"260,5\") →", type(err).__name__, "—", err)

print()
print("== ақшаны неге float-пен санамайды")
print("0.1 + 0.2 =", 0.1 + 0.2)
print("0.1 + 0.2 == 0.3 →", 0.1 + 0.2 == 0.3)
print("тиынға дейін дөңгелектедік:", round(0.1 + 0.2, 2))
print("Decimal-мен:", Decimal("0.1") + Decimal("0.2"))
print("Decimal шыншыл салыстырады →", Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))

print()
print("== иә, жоқ және бос")
print("bool(0):     ", bool(0))
print("bool(260):   ", bool(260))
print('bool(""):    ', bool(""))
print('bool("0"):   ', bool("0"), "← жол бос емес, демек ақиқат")
print("bool(None):  ", bool(None))
print("None — нөл де, бос жол да емес:", None == 0, None == "")

print()
print("== салыстыру мен логика")
budget = 1000
print("екеуіне жетеді:", price * count <= budget)
print("жетеді әрі данасы 300-ден қымбат емес:", price * count <= budget and price <= 300)
print("не арзан, не аз:", price <= 100 or count <= 2)
print("300-ден қымбат емес:", not price > 300)

print()
print("== == мәндерді салыстырады, is — бір нысан ба")
first = [260, 2]
second = [260, 2]
print("first == second:", first == second)
print("first is second:", first is second)
print("first is first:  ", first is first)
nothing = None
print("бос мәнді дұрыс тексеру: nothing is None →", nothing is None)
```

## Талдау

### Айнымалы — мәннің аты

```python
price_text = "260"
count = 2
```

`=` белгісі «тең» емес, «меншікте» деген сөз: оң жақта мән, сол жақта ат, енді ол сол атпен белгілі. Аттарды кіші әріппен жазады, сөздерді астыңғы сызықпен бөледі — `PriceText` емес, `price_text`. Бұл қыңырлық емес: бүкіл Python солай жазады, әрі бөтен код үйреншікті оқылады.

### Тип — мәннің не істей алатыны

`type()` мәннің не екенін көрсетеді:

```
жол: 260 <class 'str'>
сан: 260 <class 'int'>
```

Экранда олар бірдей көрінеді. Ал өздерін басқаша ұстайды: `"260" + "260"` `260260` береді — жолдар жабысты; `260 + 260` `520` береді.

Python бұл кезде ешқандай қате жасаған жоқ. Ол не қалағаныңызды болжамайды: жолдарды қосудың өз мағынасы бар, әрі ол сол мағынаны пайдаланды. Байқамасаңыз, қатені сіз жасар едіңіз.

Ұзаққа жететін төрт тип: `int` — бүтін, `float` — жылжымалы нүктелі, `str` — жол, `bool` — ақиқат немесе жалған. Бесіншісі — `None`, ол туралы төменде.

### Айналдырулар мен олардың шегі

`int("260")` сан береді. `int("  260  ")` да: шеттегі бос орындарға шыдайды. Ал `int("260,5")` істей алмайды:

```
int("260,5") → ValueError — invalid literal for int() with base 10: '260,5'
```

Ондық бөлгіш ретіндегі үтір — қазақстандық әрі ресейлік жүктемелерде әдеттегі нәрсе, ал Python ол туралы білмейді. Мұндай жолды алдымен жөндейді (`replace(",", ".")`), содан кейін `float`-қа айналдырады.

Кері айналдыру — `str(260)` — санды мәтінге жабыстыру керек болғанда қажет. Дегенмен бұл үшін өткен сабақтағы f-жолды жиірек алады.

> **Елестетіп көріңіз.** Қағазға жазылған телефон нөмірі әрі қоңыраудың өзі. Қағазда бұл — мәтін: оны көшіруге, басқасына жабыстыруға болады. Тергенше, оған қоңырау шалу мүмкін емес.

### Ақшаны неге `float`-пен санамайды

Сабақтағы ең маңыздысы:

```
0.1 + 0.2 = 0.30000000000000004
0.1 + 0.2 == 0.3 → False
```

Бұл Python-ның қатесі де, ерекшелігі де емес. `float` санды екілік жүйеде сақтайды, ал `0.1` екілікте — ондықтағы `1/3` сияқты шексіз бөлшек. Дөңгелектеуге тура келеді, әрі үтірден кейінгі үшінші таңбада құйрық шығады.

График үшін бұл маңызды емес. Ақша үшін — маңызды: тиындар жиналады, әрі чектің сомасы кассадағы қорытындымен сәйкес келмейді.

Екі шешім, екеуі де шығыста:

- **көрсеткенде дөңгелектеу**: `round(0.1 + 0.2, 2)` `0.3` береді. Бухгалтерияға емес, адамға санағанда жарайды;
- **`Decimal`-мен санау**: `Decimal("0.1") + Decimal("0.2")` дәл `0.3` береді, әрі салыстыру `True` қайтарады. Назар аударыңыз: `Decimal`-ды `float`-тан емес, **жолдан** алады, — әйтпесе құйрық қосудан бұрын ішке түседі.

### `True`, `False` және `None`

`bool` — екі мән: `True` мен `False`. Бірақ ақиқаттық бәрінде бар, әрі міне осы жерде тұзақ:

```
bool(0):      False
bool(""):     False
bool("0"):    True ← жол бос емес, демек ақиқат
bool(None):   False
```

`"0"` жолы — ақиқат, өйткені ол бос емес. Мәтінмен келген дерек мұнда әсіресе құлықпен өтірік айтады: CSV-ден келген `"0"` `if value:` тексеруінде ақиқат болып шығады, нөлді білдірсе де.

`None` — «ештеңе жоқ» дегенді білдіретін бөлек мән. Бұл нөл де, бос жол да емес: `None == 0` `False` береді. Ол деректе олқылық болғанда керек — ал нағыз кестелерде олқылық әрқашан бар.

### `and`, `or`, `not`

Белгінің орнына үш сөз — сөйлем сияқты оқылады:

```python
print("жетеді әрі данасы 300-ден қымбат емес:", price * count <= budget and price <= 300)
```

`and` — екеуі де ақиқат болғанда ақиқат. `or` — ең болмағанда біреуі. `not` — аударып тастайды. Күмәндансаңыз, жақша қойыңыз: олар тегін, ал кейін талдау қымбат.

### `==` мәндерді, `is` нысандарды салыстырады

```
first == second: True
first is second: False
```

Ішіндегісі бірдей екі түрлі тізім **тең**, бірақ бұл бір нысан емес. `==` «іші бірдей ме» деп сұрайды, `is` — «бұл жадтағы бір нәрсе ме».

Тәжірибелік ереже: `is` тек `None`-мен қолданылады — `if value is None:`. Қалғанының бәріне `==`. `if value == None` деп жазсаңыз, ол көбіне істейді, бірақ олай жазбайды.

## Өз сөзіңізбен айтыңыз

Қарамай, дауыстап немесе қағазға жауап беріңіз. Жауаптар — сабақтың соңында.

1. Нәтиже керегі емес болса да, `"260" + "260"` неге қате емес?
2. `0.1 + 0.2`-нің несі дұрыс емес әрі ақшаны қалай санау керек?
3. `bool("0")` неге ақиқат?

## Тапсырма

**Міндетті.** Чектен үш **салмақты** алыңыз — олар бөлшекпен жазылады, әрі сабақ не үшін жазылғаны дәл соларда көрінеді: `"1,15"`, `" 0,25 "`, `"0,2"` (килограмм). Әрқайсысын санға айналдырыңыз (екеуі жөндеуді қажет етеді), қосыңыз әрі соманы екі таңбалы f-жолмен басып шығарыңыз. Содан кейін сол соманы `Decimal` арқылы санап, екі нәтижені `==` арқылы салыстырыңыз.

Басылған жолдар бірдей болады — екеуі де `1.60` көрсетеді, — ал `==` `False` қайтарады. Ақшаны неге `Decimal`-мен санайтынының жауабы осы.

**Қалауыңызша.**

- Тексеріңіз: `0.1 + 0.2 + 0.3 == 0.6` ме? Ал `round(0.1 + 0.2 + 0.3, 2) == 0.6` ше?
- `5`, `5.0`, `"5"`, `True`, `None` үшін `type()` басып шығарыңыз — бес түрлі жауап.
- Бір бос орыннан тұратын `" "` жолы үшін `bool(" ")` нешеге тең екенін өз мысалыңызда анықтаңыз.

## Жобада бұл қайда тұрады

Шолу бөтен деректе жұмыс істеудің бірінші ережесін алады: мәтінмен келді — санға келтір әрі не шыққанын тексер. Әрі қарай бұл мәндерді тізімге, содан кейін кестеге жинаймыз.

Қарыздар. Бір жолды қолмен жөндедік, ал файлда олар мыңдап болады — бұл циклдер. Ештеңе сақтаған жоқпыз — бұл тізімдер мен сөздіктер. Әрі «айналдыру шықпаса — жолды өткізіп жібер» дей алмаймыз: бұл — ерекше жағдайлар сабағы.

## Жауаптар

1. Өйткені жолдарды қосудың өз мағынасы бар — жабыстыру, — әрі Python соны пайдаланды. Ол ниетті болжамайды; типтерді жазған адам қадағалауға тиіс.
2. `float` сандарды екілік жүйеде сақтайды, онда `0.1` — шексіз бөлшек, сондықтан `0.30000000000000004` құйрығы шығады. Адамға көрсету үшін `round` жетеді, ақша үшін `Decimal` алады әрі оны жолдан жасайды. Ал `float` пен `Decimal`-ды `==` арқылы салыстыру — нашар келісім: не екеуін де керекті таңбаға дейін дөңгелектеңіз, не бірінші таңбадан соңғысына дейін `Decimal`-мен санаңыз.
3. Өйткені жолдың ақиқаттығы мазмұнымен емес, ұзындығымен анықталады: `"0"` бос емес, демек ақиқат. Бос жол `""` — жалған.
